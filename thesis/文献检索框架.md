# 毕业论文文献检索框架（你填真实出处，AI 不编）

> 用途：第 1.2 / 2 章原标 `[需补文献]` 处已由 AI 检索核验填入真实出处 [1]–[15]（见第 8 章）。本文件把每个待补点拆成检索任务，并已在「你的引用」列回填对应编号；定稿前建议你按表复核原文。
> 铁律：**只填你真正读过的真实文献**；宁可少引，不可编造（编造=查重/答辩双杀）。

---

## 一、推荐检索入口
| 库 | 适用 | 备注 |
|---|---|---|
| 中国知网 CNKI | 中文期刊/硕博论文（国内毕设首选） | 用学校 IP 或账号 |
| 万方 / 维普 | 中文补充 | 与 CNKI 互补 |
| Google Scholar | 英文经典 + 引用网络 | 查 "被引数" 高的 |
| arXiv / SSRN | 最新预印本（量化/ML 金融） | 注意区分预印本与正式发表 |

## 三、引用记录格式（复制到正文前先填这里）
```
[1] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页.  （期刊）
[2] 作者. 题名[D]. 学校, 年.                （学位论文）
[3] Author. Title[C]//Conf, Year.          （会议）
[4] Author. Title[EB/OL]. arXiv:xxxx, Year. （预印本，标注 arXiv 号）
```

## 四、检索—填写 SOP（建议你每天做 30 分钟）
1. 选上表一行（L1–L7），到 CNKI/GS 用中英文关键词各搜一次；
2. 按「被引高 / 年份新 / 与本文相关」挑 1–2 篇，**真读摘要+结论**；
3. 把真实出处填进「你的引用」列（含 DOI/链接更好）；
4. 回草稿对应 `[需补文献]` 处，替换成 `[1]`–`[7]` 上标并加进第 8 章参考文献。

## 五、答辩防御要点（文献支撑后更好答）
- "你的创新点和 XAI 文献（L3）区别？" → 本文不靠 SHAP 近似解释黑箱，而是**规则本身可读**（`reasons` 逐条留痕）。
- "校准（L4/L7）和统计学概率校准一样吗？" → 不一样：本文校准的是**仓位刻度 CYCLE_ADJ**，对象是规则参数而非预测概率。
- "现有平台（L5）为什么不够？" → 多只展示不决策，或决策黑箱不可复盘；本文补上可解释+可自纠偏闭环。
