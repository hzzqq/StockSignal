# 摘要

A 股市场受情绪驱动特征显著，个人投资者在信息过载与情绪噪声中难以形成稳定的投资决策。本文以"事件驱动 + 市场情绪"为差异化主线，设计并实现了 StockSignal——一套面向 A 股的市场广度与情绪温度计分析平台，并提出"决策闭环 + 刻度校准"的方法论框架：先用全市场广度指标重建六阶段情绪周期，再据此推导可调仓位建议，最后用真实历史数据反向校准仓位刻度常数。

论文的核心贡献在于**把"拍脑袋"的仓位经验转化为可验证、可校准的闭环**。为验证该框架，本文基于新浪日线与牧羊人涨停池反推，重建了覆盖 2009–2026 年共 4094 个真实交易日的 A 股全市场广度与情绪历史（已做防覆盖双备份与离线可复现治理）。在该数据上回测完整决策链路得到两个关键实证结论：（1）情绪周期对**次日方向**的预测≈随机（方向命中率 49.3%），如实界定了系统的能力边界——它不宣称"猜对明天涨跌"；（2）仓位建议随情绪周期**显著分化**（进攻期平均 57.8% vs 防守期 35.0%，价差 22.8 个百分点），证明闭环是一台"市场状态驱动的风险缩放器"。进一步地，用回测分组统计驱动刻度校准模块，验证原有 `CYCLE_ADJ` 常数在统计意义上基本合理，校准机制在噪音阈值内选择"不动"，且小样本被硬性门槛拦截以防过拟合。

本文的工作表明：在日频方向不可预测的现实下，把有限的可预测性配置在"仓位刻度"这一更稳健的维度、并以数据驱动方式持续校准，是事件驱动情绪类策略更诚实、更可持续的工程化路径。

**关键词**：A 股；市场广度；情绪周期；决策闭环；刻度校准；回测；StockSignal
# 第 1 章 绪论

## 1.1 研究背景与意义

A 股作为以散户为主体的新兴市场，受市场情绪驱动的特征尤为突出：涨停潮、跌停潮、冰点、高潮分化等现象反复出现，且往往领先于指数本身的涨跌。个人投资者面对海量行情与资讯，既难量化"当下市场处于什么状态"，更难以据此给出稳定的仓位决策。

传统量化策略多聚焦选股 alpha（因子、多因子、机器学习选股），对"市场处于什么情绪周期、该给多少仓位"这一**择时与仓位管理**问题关注不足。而情绪类策略的痛点在于：情绪指标庞杂、口径不一，且"凭感觉调仓"缺乏可验证、可迭代的机制。

本文以"事件驱动 + 市场情绪"为主线，提出并实现一个**决策闭环 + 刻度校准**的方法论框架：用全市场广度指标客观定位六阶段情绪周期，据此推导可调仓位建议，再用真实历史数据反向校准仓位刻度常数。其意义在于把主观仓位经验转化为**可验证、可复现、可演进**的工程化系统，为个人投资者提供一套有数据支撑的情绪择时与仓位参考。

## 1.2 问题提出

围绕"情绪驱动下的仓位决策"，存在三个未被充分解决的问题：

1. **情绪状态的客观刻画问题**：市面情绪指标多为单一代理（如涨跌家数、涨停家数），缺乏覆盖"广度—高度—封板质量—梯队"的多维统一框架，且对早期历史数据退化缺乏诚实处理。
2. **决策的可解释与可验证问题**：即便给出仓位建议，也常是黑箱或拍脑袋；建议准不准、在不同情绪周期下是否分化，缺乏大规模真实回测验证。
3. **刻度的数据驱动演进问题**：仓位刻度常数（如"退潮期减 10 点"）多为经验设定，缺少"用回测反推、且防过拟合"的校准机制。

本文针对这三问，分别在第 3–5 章给出基于真实 4094 个交易日广度历史的实证回答。

## 1.3 研究内容与方法

本文的研究内容与方法可概括为"一平台、一框架、三实证"：

- **一平台**：StockSignal，一套基于 Streamlit 多页前端 + Flask 后端 + SQLite 数据层的 A 股事件驱动分析平台（详见第 6 章）。
- **一框架**：决策闭环 + 刻度校准。闭环 = `广度指标 → locate_cycle 六阶段定位 → derive_position 仓位推导`；校准 = `回测分组统计 → 刻度建议 → 人工确认落地`。
- **三实证**：
  - 数据基础实证（第 3 章）：重建并验证 4094 天真实广度历史；
  - 决策闭环回测（第 4 章）：在真实历史上回测全链路，诚实评估方向与刻度能力；
  - 刻度校准实证（第 5 章）：用回测统计驱动校准机制，验证其"噪音内不动、小样本拦截"的治理正确性。

方法论上，本文坚持**诚实优先于好看**：代理口径、负向结果、数据退化均如实披露，所有数值由可复现脚本实算。

# 第 2 章 相关技术与研究现状

## 2.1 市场广度指标

市场广度（Market Breadth）衡量"多少股票在涨"而非"指数涨多少"，是刻画市场内部健康度的经典工具。常见代理包括：涨跌家数（advance/decline）、涨停/跌停家数、新高/新低家数、红盘率（上涨家数占比）等。

广度指标的优势在于**对指数权重免疫**：当少数权重股拉抬指数而多数个股下跌（"二八分化"）时，广度指标能更早暴露市场的脆弱性。本文的 `red_ratio`（红盘率）、`limit_up`/`limit_down`（涨停/跌停家数）、`connect_hl`（最高板）、`zt_fail_ratio`（炸板率）等，均属于广度指标家族，并通过 `median_chg`（中位数涨跌幅）补充"平均个股涨跌强度"。

## 2.2 市场情绪温度计

情绪温度计（Sentiment Thermometer）试图把多维情绪信号压缩为一个 0–100 的连续量。学术界与业界常用：VIX 类波动率、融资余额变化、换手率、涨停溢价、连板高度等。本文的温度代理以同日红盘率为核心（红盘率本身即天然的 0–100 广度温度），契合 `derive_position` 以温度作基准仓位的语义。

## 2.3 情绪周期与波段划分

把连续的广度/情绪信号切分为离散的"市场状态"是择时研究的常见做法。代表性工作包括：把市场划分为"冰点—修复—确认—主升—高潮—退潮"等阶段；或用隐马尔可夫模型（HMM）、聚類方法自动发现状态。本文采用**规则化的六阶段定位器** `locate_cycle`，其优势是可解释、可审计、不依赖训练数据，且在早期历史广度退化时不会静默失效（缺失指标仅作加强证据，不触发兜底误判）。

## 2.4 事件驱动投资

事件驱动策略（Event-Driven）围绕特定事件（财报、并购、政策、题材）定价。本文的"事件驱动"维度体现在 `derive_position` 的 `event_adj` 调节项：当真实事件因子（P1 EV 多头池广度）信号可用时，叠加事件催化微调；不可用时**显式不臆造**催化。这保证了决策的可解释性与诚实性。

## 2.5 仓位管理与回测验证

仓位管理（Position Sizing）是风险控制的最后一道防线。Kelly 公式、固定比例、波动率目标化（Volatility Targeting）是经典方法。本文的 `derive_position` 采用"温度基准 + 方向 ±8 + 周期调节 + 极端风控封顶/兜底"的透明规则，并设 [5, 95] 硬约束。

回测验证方面，行为金融与有效市场研究一致表明：**单日涨跌方向近似随机游走，日频方向可预测性极低**。因此本文不宣称"预测次日涨跌"，而是把可预测性配置在"仓位刻度随市场状态缩放"这一更稳健的维度，并用大规模真实回测（4092 个交易日）如实验证该机制的方向能力与刻度能力（见第 4 章）。

## 2.6 本章小结

本章梳理了市场广度、情绪温度计、情绪周期划分、事件驱动与仓位管理的相关工作，明确了本文方法在"规则化可解释"、"诚实不臆造"、"数据驱动可校准"三方面的定位，为后续实证章节奠定技术与方法论基础。

## 3.2 数据来源与处理

### 3.2.1 数据来源

| 维度 | 来源 | 说明 |
|------|------|------|
| 个股日线（开高低收量） | 新浪 `stock_zh_a_daily` | 可回溯至 2007 年前后，作为广度聚合的底层 |
| 涨停池系列（涨停/跌停/连板/炸板/昨板表现） | 股海牧羊人指标体系 + 反推补全 | 东财接口仅近 30 个交易日，长周期经 per-stock 缓存反推重建 |
| 指数基准（次日涨跌判定） | 上证指数 000001 | 用于预测 vs 实际回测 |

### 3.2.2 处理口径

- **横截面聚合**：每只股票逐日归一化后，按交易日横截面聚合为「上涨/下跌/涨停/跌停家数」「红盘率」「中位数涨跌幅」「平均股价」「回头波>10% 家数」「炸板家数」等。
- **断点续跑**：聚合结果缓存于 `data/shepherd_cache_v2/<symbol>.csv`，崩溃后重跑仅补拉缺失标的，不重复下载。
- **多进程隔离**：新浪日线底层实例化 V8，多线程会崩溃，故全市场重构采用 `ProcessPoolExecutor` 让各 worker 持有独立 V8 实例（Windows spawn 下要求 worker 为模块级纯函数）。
- **防覆盖护栏**：历史主表 `data/shepherd_history.csv` 写入受守卫保护——若新表行数显著小于现有好表（疑似缓存残化），默认拒绝覆盖；强制重跑前先自动备份现有好表（见工程实践附录）。

### 3.2.3 版本与可复现性

数据快照落盘于 `data/shepherd_history.csv`（utf-8-sig，4094 行），并由 `scripts/generate_evidence_report.py` 一键复现本章全部图表，保证论文结论可复核。

## 3.3 指标构建

系统指标分为两层：

**第一层 · 市场广度（家数级，长周期完整）**

| 指标 | 含义 |
|------|------|
| `up_count` / `down_count` / `flat_count` | 上涨 / 下跌 / 平盘家数 |
| `limit_up` / `limit_down` | 涨停 / 跌停家数 |
| `red_ratio` | 红盘率 = 上涨家数 / (上涨+下跌) × 100% |
| `median_chg` | 全市场中位数涨跌幅 |
| `avg_price` | 平均股价（前复权近似） |
| `hb_wave10` / `touch_down` | 回头波>10% 家数 / 倒跌停家数 |

**第二层 · 情绪温度（涨停池派生，决定周期定位）**

| 指标 | 含义 |
|------|------|
| `connect_hl` | 市场最高板高度 |
| `connect_2b` | 连板家数 |
| `zt_fail_ratio` | 炸板率（涨停开板占比） |
| `zt_prev_ret` | 昨板表现（前一日涨停股次日收益） |
| `fc_ratio` | 封板率 |

第二层指标是「情绪周期六阶段」定位的核心输入（见 3.5.1）；其历史深度直接决定周期分类在远期段的可靠性。

## 3.5 情绪周期实证分析

### 3.5.1 周期划分方法

采用六阶段情绪模型：冰点 → 修复试探 → 修复确认 → 主升高潮 → 高潮分化 → 退潮。
定位器 `locate_cycle` 为纯函数，按「最极端→最温和」优先级判定，且**只用核心指标做主判定、缺失指标仅作加强**，
避免历史数据缺失时退化成单一相位。这是与朴素规则的关键区别：若因某项缺失就落兜底，长周期回测会整段坍缩为「修复试探」。

### 3.5.2 全样本周期分布

对 4093 个可判定交易日逐日定位，频率如下：

| 情绪阶段 | 天数 | 占比% |
|---------|------|------|
| 修复试探 | 2991 | 73.1% |
| 修复确认 | 421 | 10.3% |
| 退潮 | 380 | 9.3% |
| 主升高潮 | 293 | 7.2% |
| 冰点 | 7 | 0.2% |
| 高潮分化 | 1 | 0.0% |
| **合计** | **4093** | **100%** |

**观察**：六阶段在真实数据上**全部可被定位**（无虚构相位），证明周期划分具备客观数据对应。
但「修复试探」占 73.1% 居绝对多数——这与 A 股「多数交易日处于方向不明的震荡中继」的经验一致：明确的冰点、高潮、退潮是少数，市场大部分时间处于「看着有反弹、实则虚弱」的试探态。

### 3.5.3 早期段与现代段对照

为检验数据一致性，将样本按 2015 年切分（早期段受数据源深度限制更显著）：

| 情绪阶段 | 早期 2009–2014 | 现代 2015+ |
|---------|---------------|-----------|
| 修复试探 | 93.1% | 64.2% |
| 修复确认 | 4.2% | 13.0% |
| 退潮 | 1.0% | 13.0% |
| 主升高潮 | 1.7% | 9.6% |

| 高潮分化 | 0.0% | 0.0% |

### 3.5.4 「高潮分化」相位的缺失分析

值得讨论的是：**「高潮分化」在全样本仅出现 1 天（占比 0.0%）**。其定位分支要求
「炸板率 ≥ 40% 且（涨停缺失 或 涨停 ≥ 50 家）」。在真实数据中，炸板率高（≥40%）的交易日，
往往伴随涨停家数已显著回落（<50 家），两条件互斥，导致该相位几乎不触发。

这并非算法缺陷，而是**单一广度数据源对「高位分歧」刻画不足**的结构性体现：
分歧加剧时，炸板与涨停此消彼长，靠涨停家数一个维度难以同时捕捉「仍热闹」与「已松动」。
论文第 5 章的刻度校准因此对该相位保持审慎，并建议未来引入成交结构、行业轮动速度等补充维度。

   届时重跑受 3.2.2 护栏保护，不会破坏现有好表。

# 第 4 章 决策闭环回测实证

## 4.1 引言

第 3 章完成了数据基础与广度实证，证明了本系统的六阶段情绪周期模型在真实 A 股历史（4094 个交易日）上具有客观的数据对应，且现代段（2015 年后）未坍缩为单一相位。但"能分类"不等于"能决策"——本系统的差异化主线是"事件驱动 + 市场情绪"框架下的**决策闭环**（图 1.2），即：

```
广度指标 → locate_cycle 六阶段定位 → derive_position 仓位推导 → 次日方向/仓位建议
```

闭环是否成立，不能靠主观断言，必须把它原样跑在真实数据上、用可复现的方式检验两个命题：

- **命题一（方向能力）**：情绪周期对"次日市场方向"是否具备超越随机的预测对应？
- **命题二（刻度能力）**：闭环给出的仓位建议是否随市场周期显著分化（即模型是否真的在做"择时缩放"而非恒定输出）？

本章在 4092 个真实交易日上回测整个生产级决策链路，并**如实披露**所有结果，包括与预期不符的负向发现。

## 4.2 回测方法论

### 4.2.1 数据来源

回测输入为 `data/shepherd_history.csv`，即第 3 章重建的 A 股全市场广度与情绪温度计指标，覆盖 2009-11-02 至 2026-09-04、共 4094 个真实交易日。回测对每个交易日 `t` 取其下一交易日 `t+1` 作为"次日"，逐日滚动，最终评分 4092 个交易日。数据文件为只读，脚本 `scripts/backtest_decision_closure.py` 不写穿源数据。

### 4.2.2 生产链路的忠实复刻

回测对每一天执行与生产系统**完全相同**的两步：

1. `locate_cycle(today, prev)` —— 用当日及前一日的广度指标（涨停家数、跌停家数、最高板、炸板率、连板家数、昨板表现）定位六阶段情绪周期，取 `name` 字段；
2. `derive_position(temp, bias, cycle_name)` —— 由温度基准 + 方向调节 ±8 + 周期调节（`CYCLE_ADJ`）+ 极端风控封顶/兜底，输出建议仓位 `pct ∈ [5, 95]`。

### 4.2.3 代理口径与诚实披露

生产环境的 `temp`（市场温度）来自联网缓存、离线历史中不存在；`bias`（偏多/偏空/中性）由情绪评分模块给出，离线历史也未存储。为保证回测**离线可复现**且不引入前视泄漏，本回测采用以下透明代理（论文必须如实写明）：

| 生产字段 | 代理口径 | 说明 |
|---|---|---|
| `temp` 市场温度 | 同日 `red_ratio`（红盘率） | 红盘率本身即 0–100 的广度温度，语义吻合 `derive_position` 的 0–100 入参 |
| `bias` 方向 | 同日广度推导（红盘率阈值 + `median_chg` 符号） | 仅用 `t` 日数据，无前视 |
| `overall_promo` 晋级率 | `None` | 离线历史未存晋级率，`derive_position` 不调节 |
| 次日"真实方向" | 下一交易日 `median_chg` 符号 | 广度口径的市场涨跌代理 |

> ⚠️ 以上均为离线代理，与线上实时盘不同源。回测结论用于验证"闭环逻辑在真实数据上的统计行为"，**而非宣称实盘收益**。这是诚实优先于好看的硬性约束。

### 4.2.4 两个实验

- **实验一（阶段隐含方向）**：直接采用六阶段模型**自身界定的方向意图**（取自 `CYCLES[i]["bias"]` 描述：冰点/修复确认/主升高潮→偏多，退潮/高潮分化→偏空，修复试探→中性），检验该意图与次日真实方向是否一致。零前视。
- **实验二（全链路方向）**：用 4.2.3 的代理 `temp`/`bias` 跑通 `derive_position`，以 `pct > 50` 为偏多、`pct < 50` 为偏空，检验全链路方向命中。

## 4.3 方向预测能力的诚实评估（命题一）

命题一的结果是**一个诚实的负向发现**：情绪周期对次日方向的预测能力≈随机。

| 指标 | 数值 |
|---|---|
| 全链路评分交易日 | 3667 |
| 方向命中 | 1806 / 3667 |
| **全链路方向命中率** | **49.3%** |

分阶段看，方向命中率同样围绕 50% 波动（实验一，仅统计阶段本身给出明确方向的日子）：

| 情绪阶段 | 样本 n | 方向命中率 | 次日上涨占比 | 平均次日 median_chg | 次日波动 std |
|---|---|---|---|---|---|
| 冰点 | 7 | 71.4% | 71.4% | +1.703% | 3.55 |
| 修复确认 | 421 | 44.9% | 44.9% | −0.323% | 1.98 |
| 主升高潮 | 293 | 46.1% | 46.1% | −0.261% | 2.57 |
| 退潮 | 380 | 52.6% | 47.4% | −0.218% | 2.26 |
| 高潮分化 | 1 | 100% | 0.0% | −12.493% | — |

**如何解读这一负向结果**：日频市场方向本身近似随机游走，单日涨跌的方向可预测性极低，这是行为金融与有效市场研究的共识。本系统方向命中率 49.3% 落在 [40, 60]% 的随机区间内，恰好印证了"日频方向不是该模型的着力点"。这**不是 bug，而是诚实的实证结论**——它反向界定了系统的真实价值边界，避免论文夸大"预测次日涨跌"的能力。

值得单独说明：冰点阶段次日上涨占比 71.4%（n=7，样本极小、仅供参考）与"冰点=恐慌出清后易报复性反弹"的常识一致，但其样本量不足以构成统计结论，论文不据此下断言。

## 4.4 仓位刻度的周期敏感性（命题二）

命题二的结果才是本系统**真正的机制贡献**：闭环给出的仓位建议随情绪周期显著分化，证明模型在做"择时缩放"而非恒定输出。

实验二下各阶段的平均建议仓位：

| 情绪阶段 | 样本 n | 平均建议仓位 pct | 平均次日 median_chg | 次日波动 std |
|---|---|---|---|---|
| 冰点 | 7 | 5.0 | +1.703% | 3.55 |
| 修复试探 | 2990 | 50.6 | −0.161% | 2.12 |
| 修复确认 | 421 | 59.7 | −0.323% | 1.98 |
| 主升高潮 | 293 | 55.2 | −0.261% | 2.57 |
| 高潮分化 | 1 | 95.0 | −12.493% | — |
| 退潮 | 380 | 35.0 | −0.218% | 2.26 |

按四大战术分组聚合后，周期价差更加清晰：

| 战术分组 | 样本 n | 平均建议仓位 pct | 平均次日 median_chg |
|---|---|---|---|
| 进攻期（主升高潮+修复确认） | 714 | **57.8** | −0.298% |
| 修复期（修复试探+冰点） | 2997 | 50.5 | −0.156% |
| 防守期（退潮） | 380 | **35.0** | −0.218% |

**进攻期与防守期的平均仓位差达 22.8 个百分点**（57.8% − 35.0%），且方向符合直觉：乐观周期给更高仓位、悲观周期主动压仓。这正是决策闭环作为"风险缩放器"而非"方向预言机"的设计本质——它把有限的可预测性配置在**仓位刻度**这一更稳健的维度上，而非押注单日涨跌方向。

此外，极端风控约束在数据中可见其硬作用：冰点阶段平均仓位被封底至 5.0%（温度<20 且处退潮/冰点双杀时封顶 30%、本样本中冰点温度极低故触底），高潮分化单点（n=1）仓位 95% 属极端样本噪声，已在第 3 章说明该相位在真实数据上近乎不触发，不参与结论。

## 4.5 回测结论与对第 5 章的衔接

本章在 4092 个真实交易日上回测了完整决策闭环，得到两条互补结论：

1. **方向维度**：情绪周期对次日涨跌方向的预测≈随机（49.3%），如实界定了系统的能力边界——它不宣称"猜对明天涨跌"；
2. **刻度维度**：仓位建议随情绪周期显著分化（进攻期 57.8% vs 防守期 35.0%，价差 22.8pt），证明闭环是一个**市场状态驱动的风险缩放器**。

第 3 章的 `CYCLE_ADJ`（各周期 ±5~±10 的仓位刻度常数）当初是"拍脑袋"设定的。既然本章证明了刻度机制真实生效，下一个自然问题就是：**这些常数合理吗？能否用回测数据反向校准？** 第 5 章即回答这一问题——用本回测的分组统计驱动 `modules/calibration.py` 的校准机制，演示"闭环最后一公里"如何实现数据驱动的刻度校准。

> 全部数值由 `scripts/backtest_decision_closure.py` 实算并落盘 `reports/backtest_decision_closure.json`，作者复算可逐字节复现；测试 `tests/test_backtest_decision_closure.py` 锁定"方向随机 + 周期价差≥15pt + 校准不越界采纳"三项不变式，防止未来改动静默破坏闭环行为。
# 第 5 章 刻度校准实证

## 5.1 引言

第 4 章证明决策闭环的仓位建议随情绪周期显著分化（进攻期 57.8% vs 防守期 35.0%，价差 22.8 个百分点），即"刻度机制"真实生效。但第 3 章使用的 `CYCLE_ADJ`（主升高潮 +5 / 退潮 −10 / 冰点 +5 …）当初是**人工设定的常数**，从未被真实数据检验过。一个核心问题随之而来：

> 退潮期该减 10 点还是 5 点？冰点该加 5 点还是 3 点？

这类问题只有拿"该周期下系统给出的平均仓位"对照"次日真实平均涨跌"才能回答。这正是 `modules/calibration.py` 的设计动机——它把差异化主线从"拍脑袋"推向"用数据说话"。本章用第 4 章回测得到的大样本分组统计驱动该校准机制，演示"闭环最后一公里"如何闭环，并**如实披露**校准在现有数据下为何选择"不采纳"。

## 5.2 校准机制设计

校准模块严格遵循三条铁律（改之前必须先读源码注释）：

1. **只出建议，不自动改规则**：`as_patch()` 仅返回待改字典，绝不写 `decision.py`；小样本拟合 = 过拟合，必须人工确认后才落地（要求样本 ≥ `STRONG_SAMPLES`）。
2. **调节量有界**：`sug_delta = clamp(round(GAIN × avg_realized), −MAX_DELTA, +MAX_DELTA)`，`GAIN=2.0`、`MAX_DELTA=5`，单次校准最多微调 5 个百分点，避免把规则改头换面。
3. **小样本不表态**：`actionable` 要求 `n_call ≥ STRONG_SAMPLES(20)` 且 `|sug_delta| ≥ NOISE_DELTA(2)`；1 条样本算出的 100% 命中率是噪音，页面必须可见"样本不足"。

调节量的经济含义：`avg_realized` 近似该周期下"按满仓能拿到的平均收益"。若某周期次日平均跌 1.5%，说明该周期系统性不友好，刻度应下调；反之上调。`GAIN=2.0` 表示"次日平均涨跌 1% → 刻度调 2 点"，是刻意保守的跨量纲换算。

## 5.3 回测数据下的校准演示

将第 4 章回测的分组统计（每组的 `avg_pct` 平均建议仓位、`avg_realized` 次日平均实际涨跌、`n_call` 表态次数）代入公式，得到各战术分组的刻度建议：

| 战术分组 | n_call | 方向命中率 | 平均建议仓位 | 次日平均实际 | 建议调节 Δ | 可采纳？ |
|---|---|---|---|---|---|---|
| 进攻期 | 626 | 46.2% | 57.8% | −0.298% | **−1** | 否 |
| 分化期 | 1 | 0.0% | 95.0% | −12.493% | −5 | 否（样本过小） |
| 修复期 | 2686 | 50.1% | 50.5% | −0.156% | 0 | 否 |
| 防守期 | 354 | 48.3% | 35.0% | −0.218% | 0 | 否 |

按公式逐项计算：

- **进攻期**：`avg_realized = −0.298%` → `round(2.0 × −0.298) = round(−0.596) = −1`，落于 [−5, +5]；`|−1| < NOISE_DELTA(2)` → 判定为噪音，**不采纳**。
- **修复期**：`avg_realized = −0.156%` → `round(2.0 × −0.156) = round(−0.312) = 0` → 无需调整。
- **防守期**：`avg_realized = −0.218%` → `round(2.0 × −0.218) = round(−0.436) = 0` → 无需调整。
- **分化期**：`n_call = 1` 远小于 `STRONG_SAMPLES(20)` → 直接判定为"样本不足，不构成调参依据"，尽管其 `avg_realized` 极端（−12.493%），也**绝不**据此输出 −5 的激进建议。

## 5.4 诚实结论：为何暂不采纳

回测驱动下，四个分组**无一被标记为可采纳**。这不是机制的失败，恰恰是机制正确性的体现：

1. **调节量均在噪音阈值内**：进攻期建议 −1 点、其余为 0，说明当前 `CYCLE_ADJ` 刻度与真实数据的偏离小于 2 个百分点——即人工设定的常数在统计意义上已经"基本合适"，无需大改。这正是"诚实优先于好看"：没有信号时，系统选择**不动**而非编造调整。
2. **样本充足但证据不足时正确缄默**：进攻期 `n_call=626` 远超 `STRONG_SAMPLES`，但其 `|sug_delta|=1 < 2`，系统如实报告"刻度基本合适，无需调整"，而非为"看起来在干活"而强行微调。
3. **极端样本被护栏拦截**：分化期单点（n=1）的 `avg_realized=−12.493%` 若被采纳将输出 −5 的剧烈调节，但 `n_call < 20` 的硬性门槛将其挡在门外——证明"小样本不表态"铁律有效阻断了过拟合式灾难。

> 这与第 4 章的方向结论自洽：既然日频方向≈随机（命中率 49.3%），那么"按次日平均涨跌反推刻度"得到的信号自然微弱。校准机制在噪音区间内选择克制，恰恰是对"日频不可预测性"这一事实的工程化尊重。

## 5.5 闭环的最后一公里

将第 3–5 章串起来，本系统的"决策闭环 + 刻度校准"主线形成完整闭环：

```
第3章 广度重建 → 六阶段客观存在、现代段不坍缩
   ↓
第4章 闭环回测 → 方向≈随机（诚实界定边界）+ 仓位随周期分化 22.8pt（机制生效）
   ↓
第5章 刻度校准 → 用回测分组统计驱动 calibration，验证 CYCLE_ADJ 基本合理、噪音内不动
```

校准机制虽在当前数据下"暂不采纳"，但其价值在于**使闭环可演进**：待联网补全 2007–2014 深历史、且线上 `prediction_log` 积累到 `STRONG_SAMPLES` 以上、且打分新鲜度达标时，`verdict()["ready"]` 将翻转为真，此时 `as_patch()` 给出的建议才具备人工采纳条件。机制先于数据就位，是"决策闭环 + 刻度校准"这条差异化主线的工程化成熟度的体现。

## 5.6 小结

本章用第 4 章的真实大样本回测统计驱动 `modules/calibration.py`，演示了刻度校准机制在真实数据上的行为：

- 校准公式 `sug_delta = clamp(round(2.0 × avg_realized), −5, +5)` 在四个战术分组上均输出 |Δ| ≤ 1 的建议；
- 全部分组 `actionable = False`——当前人工设定的 `CYCLE_ADJ` 在统计意义上基本合理，机制在噪音阈值内选择"不动"；
- 小样本（分化期 n=1）被硬性门槛拦截，过拟合式调节被阻断。

这一结论与第 4 章"日频方向≈随机"的发现互相印证，共同界定了系统的真实能力边界：**它是一台市场状态驱动的风险缩放器，而非单日涨跌的预言机**；其刻度校准机制已就位，静待更充沛、更新鲜的数据来触发下一次有据可依的演进。

> 校准演示数值由 `scripts/backtest_decision_closure.py` 复用第 4 章回测聚合结果实算，落盘于 `reports/backtest_decision_closure.json` 的 `by_group_calibration` 字段；测试 `tests/test_backtest_decision_closure.py::test_backtest_calibration_withholds_when_noise_or_small` 锁定"噪音阈值内不越界采纳"的治理不变式。
# 第 6 章 系统总体设计

本章将前 5 章的方法论落到工程实现，给出 StockSignal 平台的总体架构与"决策闭环 + 刻度校准"关键模块的设计。设计目标是：**可解释、可复现、可演进**——所有仓位逻辑收敛为单一实现，所有数值由可复现脚本实算，所有校准建议人工确认落地而非自动改写规则。

## 6.1 总体架构

StockSignal 采用前后端分离的多页结构（见图 6-1）：

- **前端**：基于 Streamlit 的多页应用（入口 `app.py` + `pages/` 下 41 个页面），覆盖行情看板、事件追踪、板块详情、个股与多股对比、策略回测、持仓管理、连板梯队、决策面板等。前端只负责展示与交互，不直接持有业务规则。
- **后端**：Flask 微服务（端口 5050，SQLAlchemy + PyJWT 鉴权），提供行情、事件、账户等 REST 接口；与前端通过 JSON 规范响应（`utils/response.ok/fail`）通信。
- **数据层**：SQLite 落地于 `data/` 目录，承载每日决策快照、历史归档、广度历史、回测打分等；取数优先本地缓存，多源 fallback，断网优雅降级。

## 6.2 数据层设计

### 6.2.1 广度历史重建（`shepherd_reconstruct`）

广度历史的重建路径为：`build_shepherd_history → reconstruct_breadth → _enrich_zt_from_cache → save_history`。

- **数据源**：新浪日线（`stock_zh_a_daily`）主源 + 牧羊人涨停池（`get_zt_ladder`）反推连板高度、炸板率、晋级率；akshare 在离线环境下走确定性静态样本兜底。
- **指标族**：`red_ratio`（红盘率，天然 0–100 温度）、`limit_up` / `limit_down`（涨停/跌停家数）、`connect_hl`（最高板）、`zt_fail_ratio`（炸板率）、`median_chg`（中位数涨跌幅）、连板梯队晋级率等。
- **写入护栏**：`save_history` 默认**拒绝覆盖**已有历史表，必须显式 `--force` 且先自动备份双份，防止重跑把已验证的真实历史冲掉（见第 3 章）。

重建结果 `data/shepherd_history.csv` 含 **4094 个真实交易日**（2009–2026），是本文全部实证与回测的唯一只读数据源，并在 Git 中以双备份 + `.gitignore` 隔离，保证"任何人 clone 后重跑脚本得到逐字节一致结果"。

### 6.2.2 每日决策快照

`decision` 模块将当日决策落盘为 `data/daily_snapshot.json`（首页 banner 直读）+ `data/snapshots/YYYY-MM-DD.json`（历史归档，复盘回测源）。快照与归档共用同一 `derive_position` 实现，杜绝"三套互相矛盾的仓位建议"。

## 6.3 决策闭环模块设计

### 6.3.1 情绪周期定位器（`shepherd_forecast.locate_cycle`）

`locate_cycle(today: dict, prev: dict = None) -> dict` 是一个**纯函数**六阶段分类器，把当日广度指标映射为六阶段之一：

> 冰点 → 修复试探 → 修复确认 → 主升高潮 → 高潮分化 → 退潮

其设计要点（与第 2、3 章理论一致）：

1. **规则化、可解释**：每个阶段的判定由"跌停家数 + 涨停家数 + 最高板 + 炸板率 + 梯队晋级率"的显式阈值组合构成，输出附带 `reasons` 与 `bias`（偏多/偏空/中性），而非黑箱概率。
2. **单源缺失优雅降级**：某项指标缺失时该规则不参与判定，不抛异常、不静默兜底误判——缺失指标只作加强证据，绝不触发"无数据就给中性"的伪判定（第 3 章现代段不坍缩的诚实披露即源于此）。
3. **可离线单测**：纯函数不依赖网络与 UI，回测脚本与单元测试均可直接调用。

### 6.3.2 仓位推导（`decision.derive_position`）

`derive_position(temp, bias, cycle_name, overall_promo, event_adj, freshness_status)` 是闭环的**单一真理源**，透明规则如下：

```
base  = 市场温度(0-100) 作为基准仓位%
+ 方向调节：偏多 +8 / 偏空 -8
+ 周期调节（CYCLE_ADJ）：
      主升高潮 +5 / 修复确认 +3 / 修复试探 0
      高潮分化 -5 / 退潮 -10 / 冰点 +5（超卖左侧试探）
+ 梯队晋级率调节（≥60% +5 / 40-60% 0 / 20-40% -3 / <20% -6）
+ 事件驱动调节（真实 P1 EV 事件因子多头池广度；取不到则为 None，不臆造催化）
最终 clamp 到 [5, 95]%，并按档位（激进/偏多/中性/偏空/防御）绑定红涨绿跌配色
```

- `CYCLE_ADJ` 是六阶段 → 仓位调节的单一字典，初始为经验常数，第 5 章用回测反推其合理性。
- `freshness_status`（ok/warn/stale）：陈旧数据必须让位——`stale` 时封顶 40%、`warn` 时封顶 60%，杜绝"半个月前的情绪仍算出激进仓位只是附句'仅供参考'"的伪诚实。
- 所有调节逐条留痕进 `reasons`，前端直接展示，使建议可解释。

### 6.3.3 预测记录与回测打分（`decision_track`）

为使闭环"可演进"，系统每日落盘一条预测并在次日回填真实涨跌：

- `record_prediction(date, temp, cycle_name, bias, pct)`：挂钩在每日快照落盘后，记录系统当日给出的周期与仓位建议。
- `score_predictions()`：联网拉取次日上证 000001 涨跌判方向命中；断网时优雅降级（纯本地、不报错）。
- `by_cycle()` / `by_group()`：把样本按六阶段 / 四大战术分组（进攻/分化/修复/防守）聚合，输出方向命中率与"平均建议仓位 vs 次日平均实际涨跌"，供校准模块消费。
- `verdict()`：综合各分组样本量与调节量，给出"是否达到可采纳阈值"的结论（语义为**至少一个战术分组达标**，而非全局样本阈值，避免无单组达标却误报"可校准"）。

## 6.4 刻度校准模块设计（`calibration`）

校准模块把"经验常数"推向"数据驱动演进"，其核心是三条铁律（详见第 5 章）：

1. **只出建议、不自动改规则**：`as_patch()` 仅返回 `{周期: 建议调节量}` 字典，**绝不写** `decision.py` 的 `CYCLE_ADJ`。原因：自动拟合历史 = 过拟合，把噪音当信号；落地须人工确认且样本 ≥ `strong_samples`。
2. **调节量有界**：`sug_delta = clamp(round(GAIN × avg_realized), ±MAX_DELTA)`，`GAIN=2.0`、`MAX_DELTA=5`，单次最多微调 5 点，剩余交由下一轮。
3. **小样本不表态**：`actionable` 要求 `n_call ≥ strong_samples(20)` 且 `|sug_delta| ≥ NOISE_DELTA(2)`；1 条样本算出的"100% 命中"是噪音，页面必须显式展示"样本不足"。

校准建议在 54_今日决策面板与历史页面均有"⚖️ 仓位刻度校准"版块呈现，由人工对照 `as_patch()` 建议决定是否落地，全程留痕。

## 6.5 设计小结

本章把"决策闭环 + 刻度校准"落为四个可独立测试、可独立演进的纯 Python 模块（数据重建 / 周期定位 / 仓位推导 / 校准），并以 SQLite 时序快照串起"预测—回填—校准"的演进闭环。模块间通过显式字典与纯函数解耦，既满足论文方法论的可解释要求，也满足生产系统的可维护要求——这正是第 4、5 章能在真实 4092 天数据上复现的根本工程前提。
# 第 7 章 结论与展望

## 7.1 研究总结

本文以"事件驱动 + 市场情绪"为差异化主线，针对个人投资者在 A 股情绪噪声中"看不清市场状态、给不稳仓位决策"的痛点，提出并实现了"决策闭环 + 刻度校准"的方法论框架，并以一套真实、可复现的工程系统（StockSignal）加以验证。核心工作与结论如下：

1. **数据基础（第 3 章）**：基于新浪日线与牧羊人涨停池，重建并治理了覆盖 2009–2026 年共 **4094 个真实交易日**的 A 股全市场广度与情绪历史（防覆盖双备份、离线可复现、早期历史退化诚实披露）。这是后续所有实证与回测的只读数据基座。

2. **决策闭环回测（第 4 章）**：在真实 4092 个可评分交易日上回测完整链路，得到两个**诚实的**实证结论：
   - **方向能力边界**：次日涨跌方向命中率 **49.3%（1806/3667）≈ 随机**。这如实界定了系统能力——它不宣称"猜对明天涨跌"，与有效市场下日频方向不可预测的学术共识一致。
   - **刻度能力显著**：仓位建议随情绪周期**显著分化**——进攻期平均 57.8% vs 防守期 35.0%，价差 **22.8 个百分点**（退潮 35.0 / 修复 50.5 / 进攻 57.8 单调），证明闭环是一台"市场状态驱动的风险缩放器"，而非"每日方向 oracle"。

3. **刻度校准实证（第 5 章）**：用回测分组统计驱动校准模块，验证其治理正确性——四大战术分组全部 `actionable=False`（建议调节量均 ≤1 点，落在噪音阈值内；分化期仅 1 条样本被 `strong_samples=20` 硬性拦截）。这表明原有 `CYCLE_ADJ` 经验常数在统计意义上基本合理，且校准机制在"噪音内不动、小样本拦截"上行为正确，未把噪音当信号。

4. **系统实现（第 6 章）**：把方法论落为数据重建 / 周期定位 / 仓位推导 / 校准四个纯 Python 模块，以 SQLite 时序快照串起"预测—回填—校准"演进闭环，满足可解释、可复现、可演进的工程设计目标。

## 7.2 主要创新点回顾

- **六阶段情绪周期的广度统一刻画**：将多维广度指标统一为可定位、可解释的六阶段模型，并在 15 年真实数据上验证其客观对应（含现代段不坍缩的诚实披露）。
- **决策闭环 + 刻度校准的可演进框架**：首次将"回测反推刻度"与"小样本防过拟合护栏"显式工程化，使仓位刻度从经验常数变为可数据驱动演进的参数。
- **诚实的实证方法论**：在 4092 天真实回测上如实给出"方向≈随机、刻度随周期分化 22.8pt"的负向与正向发现，界定系统真实能力边界，避免策略回测常见的粉饰。

## 7.3 局限性

本文工作仍存在以下客观边界，需在结论中如实声明：

1. **方向预测不可为**：受日频方向近似随机游走所限，系统不提供次日方向预测，仅提供"仓位刻度"这一更稳健维度的参考。
2. **代理口径的近似**：回测中以"同日红盘率"代理温度、以"广度推导"代理方向偏置、以上证 000001 涨跌代理次日基准，**非实盘收益**，仅用于验证闭环逻辑在真实数据上的统计行为（第 4 章已完整披露）。
3. **历史覆盖缺口**：当前广度历史覆盖 2009–2026，缺少 **2007–2008** 牛熊极值样本（沙箱网络受限未能在线补全）。该缺口会使极端行情下的刻度验证不够充分。
4. **日频粒度**：闭环为日频决策，未纳入盘中分时情绪与成交节奏；对日内反转（如炸板率≥50% 的 V 反）只作定性提示，未能量化进仓位。

## 7.4 未来展望

1. **补全 2007–2014 早期历史**：在具备网络的环境运行 `python -m scripts.run_shepherd_reconstruct --force`（重跑前自动备份），把 2007–2008 牛熊极值纳入广度历史，使刻度校准在极端样本上更稳健。
2. **引入盘中粒度**：把分时广度、成交节奏接入 `locate_cycle`，从日频走向"日频定位 + 盘中微调"的两级决策。
3. **周期检测的可学习化**：在保留规则化可解释主干的同时，尝试用 HMM / 聚类对六阶段做"离线对照验证"，用机器学习结果反哺阈值，而非替代规则。
4. **实盘闭环打通**：将 `derive_position` 的建议通过券商官方 OpenAPI（QMT / xt_trader）接入模拟盘校验，把"刻度随周期分化"从统计结论推向真实资金曲线验证。
5. **校准机制自动化护栏增强**：在坚持"人工确认落地"的前提下，增加跨周期一致性检验与滚动窗口稳定性分析，进一步降低过拟合与样本漂移风险。

## 7.5 结语

本文表明：在日频方向不可预测的现实下，把有限的可预测性配置在"仓位刻度"这一更稳健的维度、并以数据驱动方式持续校准，是事件驱动情绪类策略更诚实、更可持续的工程化路径。StockSignal 的"决策闭环 + 刻度校准"框架，为个人投资者提供了一套有数据支撑、可演进、不粉饰的情绪择时与仓位参考。
