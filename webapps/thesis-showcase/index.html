KEY RESULTS

04核心结果：两个口径，并存不冲突

回测锚定 · 离线代理回测

49.1%

整体方向命中率 = 1722 / 3507 次有方向调用；4092 个交易日打分，177 个平盘日按“平盘=无方向信息”口径剔除。来源：reports/backtest_decision_closure.json + 论文摘要。

前向实测 · 真实决策快照

37.5%

15 个真实决策快照（2026-08-31 ~ 09-21）的胜率口径。小样本，仅证明对账链路持续运行并正确落盘，不作统计宣称；快照持续累积中，命中率随样本滚动。

两个口径为什么并存不冲突？前者是离线代理回测（temp=red_ratio 等代理变量在 4092 个真实交易日上的统计行为，样本大、用于锚定系统能力边界）；后者是前向实测（系统上线后每日真实快照的对账，样本极小、只证明链路正确）。结论如实写进论文：情绪周期对次日方向的预测 ≈ 随机（49.1%），系统的价值在“仓位刻度”而非“猜方向”——进攻期平均仓位 57.8% vs 防守期 35.0%（价差 22.8 个百分点），是一台市场状态驱动的风险缩放器。
情绪阶段 → 次日方向命中率（离线代理回测）。⚠️ 冰点 n=7 为小样本（与百分比同尺寸标注），不构成独立结论；虚线 = 50% 随机基准。
ALGORITHM ITERATIONS

05三次算法改进：诚实记录，负向不包装

来源：docs/deep-learning-review-2026-10.md、docs/thesis-upgrade-gnn-v2.md、docs/thesis-upgrade-rl-v2.md（P1 同口径 head-to-head 真实重跑）。

#1 Transformer 对照 正向（modest）

方向命中 0.5130 vs GRU-Attention 基线 0.5097，IC 0.0374 → 0.0465（+24%）。

如实标注：命中差异仅 +0.0033，属“边缘但一致”的 modest 改进，不夸大。

#2 GNN 因子图 负向 · 证伪

方向命中 0.4948（低于 49.1% 锚上方基线），IC 0.0076，仅约为 GRU 的 1/5。

结论：图聚合替换主输入是结构缺陷而非改进——两次“加大加深”尝试均证伪，失败原因已写入论文。

#3 RL 仓位调制 负向 · 证伪

v1 自由动作 Actor-Critic：Sharpe -0.741（对照组 tanh 静态基线 +1.137）。

后续 v2 改为基线乘性调制修复至 +0.549，但 oracle 诊断证明该信号上调制空间不存在——“何时该用 RL”的判据本身成为方法学产出。

诚实记录：负向结果（#2 GNN、#3 RL v1）与正向结果同版面、同视觉权重展示，不删不藏不包装——它们构成了“何时该投入更复杂模型”的判据，是论文方法论的一部分。

06牧羊人情绪体系：被严格验证的规律

极端恐慌 → 次日反弹

跌停占比前 10% 时 · 次日红盘概率62.5%
基准（全部交易日）49.8%

z = +4.36，296 天样本（2007–2026 全历史 walk-forward 校准）；系统只在这一条被严格验证的规律上表态，其余日子一律诚实弃权。

温度冰点 → 次日红盘

89.7%

情绪温度冰点条件下次一交易日红盘比例（temperature_backtest.py 回测口径）。呼应“极端恐慌 → 次日反弹”的项目已知规律。

07工程质量：守卫文化

离线 AST 守卫

40+ 个守卫测试文件用源码级断言锁死约定（标准页入口、图标唯一性、废弃 API 禁用），改坏即红，不靠人肉 review。

诚实语义守卫

test_clear_cache_truthful.py 等：语义性断言（如“宣称清空的必须真清空”）+ 公开物料数字一致性守卫（页数/测试数与真实值互锁，改一处漏一处直接红）。

密钥扫描纪律

每次提交前对 diff 做 sk-/AKIA/私钥块/明文口令扫描，扫描不过不准 commit；多机协作走 FF-only，禁 force push。

小样本不表态（T3）

校准模块三铁律之一：样本不足时系统拒绝输出命中率（论文第 6 章实证 accuracy=null），宁可沉默，不给假阳性结论。
