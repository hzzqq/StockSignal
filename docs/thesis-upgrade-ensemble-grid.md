# 融合权重网格对照：现役 w=0.25 的稳健性验证——改进实验补充节

> 毕设素材 · 追加于《纯 Transformer 与 GRU+注意力机制对照实验》之后（T-265 B 路）。所有数字来自 P1 生产口径真实回测（rf=15 / top_pct=0.1 / buffer=0.1 / 长空 / 含成本），19 组配置全量跑（102 秒）。

## 一、动机

T-255 对照显示「Transformer 替换 GRU」路（v39+Transformer w=0.25）净收益劣于现役。本节回答两个补充问题：①**权重维度**上，现役 w_gru=0.25 是否已是最优？是否存在更好的融合比例？②Transformer 融合劣势是权重选择不当，还是结构性劣势？

## 二、实验设置

- 基座：v39 线性模型 z-score + GRU/Transformer z-score 加权融合（与 zz_ensemble_multi_compare 同构）。
- 网格：`v39+GRU` 与 `v39+Transformer` 各扫 w ∈ {0.05, 0.10, …, 0.40}（现役 0.25 为网格内锚点）；另设纯二路 GRU+Transformer 秩平均（无 v39 基座）w_gru ∈ {0.3, 0.5, 0.7} 作消融。
- 回测：run_backtest_continuous，horizon=10，rf=15，top 10%，buffer 10%，长空、含 DEFAULT_COST。

## 三、实验结果（真实回测，zz_ensemble_pairwise.py）

| 配置 | 净累计 | 夏普 | 回撤 | 胜率 |
|---|---|---|---|---|
| v39+GRU(w=0.25)（**现役**） | +97.65% | +1.244 | -12.02% | 0.621 |

## 四、结果分析（如实表述，不夸大）

1. **Transformer 融合劣势是结构性的，非权重问题**：v39+Transformer 全网格（w 从 0.05 到 0.40）夏普单调劣化（+1.097→+0.874），任何权重下都显著低于同权重 v39+GRU；纯 Transformer 信号与 v39 基座的融合不产生互补增益。结合 IC 更高但净收益更低的事实，可表述为：**Transformer 的增量 IC 集中在基座已覆盖的信息上，且其信号尾部特征在 top10% 截面选择中不如 GRU**。
2. **现役 w=0.25 位于平坦平台，不是最优但足够稳健**：v39+GRU 网格从 0.15 起进入夏普 1.22~1.34 的平台，w=0.40 网格最优（夏普 Δ+0.091、收益 Δ+3.6pp、回撤反而更小 -8.28%）。**但按预注册判据（Δ夏普≥0.05 且 Δ收益≥5%）未达「稳定优势」**——收益差 3.6pp 属噪声级，且单点网格最优存在选择偏差。诚实结论：**现役维持；w∈[0.30,0.40] 的更高 GRU 权重作为「值得观察的候选」留痕，由更长的样本外窗口验证后再议**。
3. **消融发现（有价值）：纯二路（无 v39 线性基座）几乎归零（-7.6%~+2.5%）**——GRU 与 Transformer 两个序列模型直接融合不能产生正收益，v39 线性基座承担了「截面中性化/风格稳定」的基础作用。这说明**序列模型的 IC 增量只有在强基座的组合框架内才能兑现**，是「信号质量 ≠ 组合收益」的又一实证。
4. 口径提醒：网格扫描基于同一段 2022–2026 样本，无独立留出集；上述「平台」结论的置信度受此限制，应表述为「稳健性验证」而非「优化结果」。
