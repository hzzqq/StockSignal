# GNN v2：从「结构缺陷」到「门控增广」——因子图卷积修复实验补充节

> 毕设素材 · 追加于《因子图卷积网络（GNN）与 GRU/Transformer 对照实验》之后（T-265 C 路）。所有数字来自 P1 同口径 head-to-head 真实重跑（walk-forward 2022–2026，500 标的、hidden=64 / seq_len=20 / epochs=15 / stride=5，与 GRU 基线锚逐项同参）。原章节的负向结果（FactorGraphGCN，IC=0.0076）**保留不删**，作为演进叙事的第一阶段。

## 一、v1 病因的精确定位（结构缺陷，非调参问题）

原章节自诊给出三条可能原因（静态图 / 信息冗余 / 池化平滑）。本轮通过结构对照把主因**钉死**在第三条的更具体形态上：

> **v1 的 GCN 因子均值池化「替换」了时序编码器的输入**——`GRU` 吃的是图聚合后的单一向量 `(B,T,gnn_hidden)`，而不是原始 38 因子序列 `(B,T,F)`。因子级判别信息在进入时序编码之前被图平滑抹掉。v1 本质上是「GRU 吃图摘要」，而非「GRU 吃原始因子 + 图交互增广」。

这一诊断的可证伪预言：只要恢复「原始因子直进 GRU」并把图信息降级为**增广项**，性能应立即回到基线量级。v2 实验证实了这一点。

## 二、v2 结构：双流门控（保底 + 增益候选）

- **主流（保底下界）**：原始因子 `(B,T,F)` 直进 GRU，与 GRUAttention 完全同构；
- **辅流（图交互）**：节点特征从单因子标量升级为 `(x_t, Δx5_t)` 二维（richer 输入），GCN 消息传递后均值池化，再经轻量 GRU 编码；
- **门控融合**：`h = h_main + tanh(gate)·h_aux`，gate 为**零初始化**可学习标量——训练起点严格等价 GRUAttention；图交互学到信息 gate 才非零，学不到则退化为基线（结构上保证不更差）。

## 三、实验结果（真实重跑，04_train_nn --model gnn_gate）

| 模型 | 方向命中率 | Δ锚(49.1%) | IC | ICIR | IC 正占比 | 训练耗时 |
|---|---|---|---|---|---|---|
| v1 FactorGraphGCN（原版，全量口径，引用） | 0.4948 | +0.0038 | 0.0076 | 0.105 | 0.568 | ~5.3 h |
| **v2 FactorGraphGCNv2（门控，本轮）** | **0.5078** | **+0.0168** | **0.0440** | 0.371 | 0.664 | ~3.4 h |
| GRUAttention（500 标的基线锚） | 0.5107 | +0.0197 | 0.0415 | 0.406 | 0.668 | 94 s |

分年 IC（v2）：0.040 / 0.043 / 0.049 / 0.048 / 0.047——全部为正。

## 四、结果分析（如实表述，不夸大）

1. **结构修复成效显著**：IC 0.0076 → 0.0440（**5.8 倍**），方向命中率 0.4948 → 0.5078（回到 49.1% 锚上方 +1.68pp），ICIR 0.105 → 0.371。诊断→预言→验证链完整，确认 v1 的失败是「图聚合替换主输入」这一结构缺陷所致，而非「图结构偏置无用」。
2. **相对基线：同量级持平，不宣称超越**。v2 相对 GRU 锚：IC +6%（0.0440 vs 0.0415）、命中率 -0.29pp、ICIR -9%——各维有胜有负，差异在噪声边缘。诚实例句：「修复后的门控 GNN 与 GRU 基线性能相当（IC 维度略优、稳定性略逊），因子图交互在本数据集上存在但微弱」。
3. **工程结论（可迁移）**：图结构偏置在时序因子模型中的正确用法是**门控增广**（gate-initialized residual）而非**输入替换**——前者结构上不差于基线、学到交互才有增量；后者把基线信息通路也交给了图。这一设计模式适用于任何「辅助结构如何接入强基线」的场景。
4. 成本如实报告：训练耗时 94 s → 3.4 h（GCN 辅流 + 双流反传），在 IC 增益仅噪声级的前提下，**性价比不支持生产切换**；本实验的价值是方法学（诊断方法 + 门控范式），不是部署新模型。
