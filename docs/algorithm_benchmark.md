### 对照发现的现有空白（下文评估的落点）

1. **无「强势新高」路线**——五路全部偏超跌反弹（A1）、趋势持有（A2）、资金/事件确认（A3/A4）、绝对动量（A5），没有一条要求「创阶段新高 + 流动性门槛」的右侧强势逻辑。
2. **推荐漏斗未接六维排雷**——`stock_risk.scan_many` 现成，但 `generate_daily_recommendation` 全程未调用；ST/高商誉/解禁临前股可能凭价量分混进 Top-K。
3. **风险只有排雷没有扣分**——六维是离散报告，融合分里没有连续的波动/换手过热反向项。
4. **无「相对大盘」口径**——A5 是绝对 20 日涨幅，牛市普涨时区分度归零。
5. **财务健康连续量化空白**——valuation 是估值带、stock_risk 是事件面，Piotroski F / Altman Z 类财务体质分没有。
6. **融合权重静态**——`ALGO_WEIGHTS` 不随市况（温度/周期）变化，弱市里趋势/动量路照常给高分。

## 一、a-stock-multi-factor-screener__skillhub（实际内容＝OneQuant 4.0 回测平台）

> ⚠️ **名实不符**：该目录名是 multi-factor-screener，SKILL.md 实为 `onequant-backtest`——一个 102 API 的本地 Flask 量化**平台**（回测/模拟盘/条件选股/风控/券商对接），附带 `faq.md`（28 问）与 `api_examples.md`。**没有任何独立的多因子算法内容**，条件选股仅三档：`limit_up` / `ma_golden` / `rsi_oversold`。

**可借鉴点**
1. **回测成本折算口径**（FAQ Q9）：回测不含佣金/印花税/滑点，实盘需折算「佣金约 0.025%（双边）+ 印花税 0.1%（卖出）+ 滑点 0.1~0.5%」。对照：项目 `_simulate(commission=0.001)` 只有一项，且未拆印花税。
2. **过拟合防线**：MA 参数禁止对单只股票逐只调优，须统一参数跑 20+ 标的验证泛化——与项目 `run_batch`/`daily_picker_backtest` 已有实践一致，属确认而非增量。
3. **精度保证矩阵 / 降级标注范式**（AkShare 超时 8 秒返回 Mock 并标 `DEGRADED`）：项目 `data_staleness` + `unavailable` 语义已覆盖且更严格（Mock 数据在项目语义里等于编造，不可用）。

**重叠度：高**。回测/条件选股/风控/模拟盘项目全有且更深（事件驱动、六维排雷、决策快照都是它没有的）。

**接入成本**：平台整体接入 = 引入第二套 Flask 服务与数据层，架构冲突，无意义；成本口径借鉴 = `backtest._simulate` 加 1~2 个参数。

**建议：❌ 不采纳平台；✅ 仅吸收「回测成本口径」小改**（见采纳清单 R10）。

## 二、stock-evaluator__skillhub（stock-evaluator-v3，单标的机构级评估）

> 面向美股/欧股的单标的深度评估 SOP：估值多法合成 + 财务健康三评分 + 价值陷阱评分 + 8 位投资家人格分 + 仓位建议。数据纪律（零编造、N/A 不填 0、来源分级）与项目诚实语义**完全同构**。

**可借鉴点**
1. **Value Trap Score（0~100，四分量加罚）**：价格动量恶化（6/12 月跑输）+ 盈利质量下滑 + 资产负债表恶化 + 「低估值是否被基本面恶化证成」四项加罚。**直击 A1 的最大短板**——A1 是 RSI2 超跌+反弹逻辑，天然爱吃「跌得深但跌得对」的飞刀；低价陷阱恰恰是「便宜有便宜的道理」。轻量版（价格动量分量 + PE/PB 分位带分量）**纯本地可算**：`valuation.fetch_pe_pb_series` 现成，价格动量从日线直取；财务分量（盈利质量/负债）后置。
2. **Piotroski F-Score（0~9）**：盈利 4 + 杠杆/流动性 3 + 运营效率 2，其中「经营现金流 > 净利润」一项与 `stock_risk.fetch_balance_sheet`、`valuation.fetch_dupont_inputs` 已有取数半重叠；项目缺现金流表接口，需补 1 个 AKShare 取数。
3. **Altman Z-Score / Beneish M-Score**：破产风险与财务操纵检测。Z 公式简单（5 个比率线性组合）；M 需 8 个指标多期数据，成本中高。与六维排雷互补（六维是事件/结构面，Z/M 是财务面）。
4. **仓位 = 信念 × 风险二维矩阵**：Strong Buy+低风险 5~8%（上限 10%）、Buy 3~5%、投机型 1~3%（上限 5%）。对照：引擎现在是「市场仓位等权 + 单票 20% 上限」，**融合分档位与排雷等级完全没进仓位公式**。
5. **DCF 40% + 相对 30% + Lynch 30% 多法合成、margin of safety ≥15%**：`valuation.py` 已有分位带/行业相对/同业矩阵（≈相对法），DCF 与 Lynch 需盈利预测数据，暂缓。

**重叠度：中**。技术面入场时机与 A1/A2 重叠；N/A 纪律与项目语义重叠（零成本确认）；财务体质与仓位矩阵是增量。

**接入成本**：Value Trap 轻量版低（本地）；F-Score/Z 中（补现金流取数 + 多期报表）；投资家人格分高且偏主观，不建议。

**建议：✅ 部分采纳**——Value Trap 轻量版（R3）、F-Score/Z-Score 中期立项（R8）、信念×风险仓位矩阵（并入 R3 落地）；❌ DCF 合成、8 投资家评分、Ichimoku 云（A2 已含一目）。

## 三、stock-selecter__skillhub（11 策略统一选股包 v3.2）

> 12 个策略（ROE/MACD 底背离/高股息/低估值/费雪成长/长期低位/近期放量/趋势/K 线形态/布林下轨/筹码集中/现金流质量），统一 0-100 评分，AND/OR/SCORE 三种组合模式，ThreadPool 并发 + HTML 报告。**最有价值的是漏斗工程学，其次是个别项目没有的因子构造。**

**可借鉴点**
1. **AND 硬门槛二道闸设计**：SCORE 加权之外的 AND 交集模式——「必须同时通过」的硬条件独立于打分。对照：引擎的六路全是软加权，无一道硬闸；六维排雷正是天然的 AND 条件（现成 `scan_many`）。
2. **MACD 底背离**（K 线斜率向下 + MACD 斜率向上 + 放量）：`technical.py` 有 MACD 无背离检测；与 A1 超跌反弹语义**高度互补**（背离=超跌反转的确认信号），纯本地可算。
3. **长期低位**（250 日价格分位 ≤25% + RSI≤40）：与 A1 的 RSI2 短线超跌口径不同（长线位置 vs 短线斜率），`valuation.py` 有 percentile 工具，本地可算；可作 A1 的加分确认或 Value Trap 的对照项。
4. **现金流质量**（经营现金流 ≥ 净利润连续 3 期 + 商誉 <30%）：商誉一半 `stock_risk.goodwill_risk` 已有；现金流部分与 F-Score 重叠，合并立项即可，不单独立项。
5. **筹码集中**（股东户数连续 3 期减少）：全新数据维度，需新增股东户数取数（AKShare 有接口），网络开销 + 稳定性待勘测。
6. **形态库**（双底/头肩底/早晨之星/杯柄/旗形/金叉）：`technical.detect_patterns` 现 6 种基础形态，扩充需逐形态写识别规则 + 负向样例测试，成本中、短线荐股增量中等。
7. **绝对锚点评分**（ROE 满分 ≥25%、放量满分 ≥3x 等）：项目融合是**候选集内相对归一化**（min-max），与绝对锚点是两种哲学——相对归一化对市况自适应更好，绝对锚点跨日可比。保持现状，仅登记差异。
8. 高股息/ROE/费雪成长/布林下轨：财务筛选类与短线荐股定位不匹配（布林与 A1 量价重叠），不采纳。

**重叠度：中**。放量/趋势/低位与 A1/A5 部分重叠；MACD 背离、筹码集中、AND 漏斗是增量。

**接入成本**：AND 闸低（模块现成）；MACD 背离/长期低位低（本地）；筹码集中中（新数据源）；形态库中。

**建议：✅ 部分采纳**——AND 排雷二道闸（R1，与 stock_risk 合并落地）、MACD 底背离（R7）、250 日低位分位（并入 R3）；⏸ 暂缓——筹码集中、形态库扩充；❌ 财务筛选策略组、布林。

## 四、ashare-short-term-trading（A 股短线决策工作流 v1.0.3）

> 四环节：交割单复盘 / 标的初筛（R00–R07 规则）/ 盘中节点评估 / 单标的因子分析。附带 `references/strategy_definitions.md`（规则全量定义）、`factor_model.md`（五类因子权重）、`ta_signals.md`（分时信号）、`scripts/intraday_strength.py`。**本批技能中算法密度最高、与现有五路正交性最强的一份。**

**可借鉴点**
1. **R00「放量新高突破」六条件规则**（核心借鉴点）：ST 过滤 + 近 3 日巨量（单日 >20 日均量 200% 或 3 日均量放大 150%）+ 连续 3 日收于 MA5 上方 + 3 日累计成交额 >24 亿 + 连续 3 日换手 ≤50% + **后复权价创阶段/52 周新高**。**与五路全部正交**：A1 吃超跌、A2 吃趋势但无新高/流动性门槛，R00 是右侧强势+流动性过滤路。本地可算部分：qfq 新高（`get_daily(adjust="qfq")` 现成）、MA5、量比、成交额（`amount` 列现成）、ST 过滤（`fetch_st_set` 现成）；**换手率需勘测/新增字段**，拿不到就按可用子集降级并如实标注。R01（量能验证突破：当日量 ≥5 日均量 150% + 破 10 日高点）可作为 R00 的宽口径版共用实现。
2. **市况自适应规则组合**：强势市用突破类（R01+R03+R07）、震荡市用回踩低吸类（R02+R04+R06）、弱势市轻仓只做底部。对照：项目有现成的温度/周期体系（`decision.load_snapshot` 已在引擎内），可映射为**温度档 → ALGO_WEIGHTS 动态微调**（高温加趋势/动量权重、低温加超跌/资金权重；快照不可用时回落到现状静态权重，不破坏诚实语义）。
3. **相对大盘强度因子**：盘中强度五因子（相对大盘 30% + 量能 20% + 均线 20% + 资金 20% + 筹码 10%）里「相对大盘」是**现有五路唯一空白口径**——A5 是绝对动量，普涨日区分度归零；个股 20 日收益 − 指数 20 日收益纯本地可算（需指数日线，fetcher 能力待勘测）。
4. **五类因子模型**（量价 30 / 资金 25 / 波动 15 / 情绪 20 / 事件 10）中**波动风险反向计分**：振幅/最大回撤越小分越高、换手过热（>50%，出货征兆）取低分——融合分目前只奖不罚，加一个连续风险扣分项是结构性补位。情绪/连板梯队维度项目无数据源，不采纳。
5. **事件窗口扣分**（临近解禁/业绩预告扣分）：`stock_risk.unlock_risk` 解禁队列数据现成，把「解禁临近」从排雷报告接入引擎做连续扣分，数据零新增。
6. **交割单复盘五维**（进场时机/大盘共振/离场时机/持仓效率/盈亏捕获率）与**盘中节点评估**：需要用户交割单与盘中分时流，项目无此数据形态，不适用。

**重叠度：中**（R01 与 A5 量能部分重叠、均线与 A1 重叠、资金与 A3 重叠）。

**接入成本**：A6 新高路中低（换手率待勘测）；市况权重低；相对强度低-中（指数日线待勘测）；波动扣分/解禁扣分低。

**建议：✅ 重点采纳**——A6 放量新高路（R2）、市况自适应权重（R4）、相对大盘强度（R5）、波动/换手过热扣分 + 解禁临近扣分（R6）。

**可借鉴点**
1. **多层传导推理框架**（直接影响→二阶传导→A 股映射 + 硬逻辑/历史映射/情绪炒作分类）：与 A4/P1 事件因子（存量信号目录 EV 模型）**互补**——P1 吃结构化目录，猎手吃实时新闻映射。但实时搜索 = 引入 LLM + 网络依赖到每日批量引擎，破坏确定性与成本模型，**不建议进 `recommend_engine`**；正确落点是 H1 `modules/research_agent.py`（多步工具调用 + 引用溯源 [S#] 恰好是它需要的证据链形态）。

3. **ST/退市/长期停牌/流动性过滤前置**：项目 fetch_st_set 现成，属确认项。
4. **降级策略**：与项目「unavailable 不硬凑」语义一致，零成本确认。

**重叠度：与 A4 中度重叠；与 H1 research_agent 高度互补。**

**接入成本**：标注层低（纯字段）；实时映射中高（走 research_agent 立项，另案）。

**建议：✅ 轻量采纳**——A4 标注层（R9）；⏸ 实时题材映射另立 research_agent 方向、须老板拍板，不进每日引擎。
