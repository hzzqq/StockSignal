## 一句话定位（30 秒电梯演讲）

> StockSignal 是一个**事件驱动的 A 股投研平台**：4 级数据源自动降级保证取数韧性，
> 核心创新是一个**可解释、可自纠偏、可回溯**的仓位决策闭环——把温度、方向、
> 周期、晋级率、事件催化显式推导成 5%~95% 的仓位，逐条输出理由，用历史回测
> 反推有界刻度建议，并每日归档对账。工程上双前端并存（v1 Streamlit 遗留只读、
> v2 React 19 生产前端），74 功能页 / 158 REST 端点 / 4760 自动化测试兜底。

## 三条不能踩的诚实红线（老板口径，别自己改）

1. **不编造数据**：任何图表/报告的数据源不足就跳过不产出；缺失显「—」，绝不补 0。
2. **不宣称实盘**：项目是投研分析工具，无真实券商下单；实盘交易端点永久留在 v1 且不迁 v2。
3. **不夸大命中率**：决策闭环回测方向命中率 **49.1%**（1722/3507，非实盘收益），
   这是诚实负结果，讲的时候要主动说「接近随机、机制自洽但无显著 alpha」——
   面试官追问时这反而是加分项：说明你不会拿小样本吹效果。
