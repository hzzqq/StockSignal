# StockSignal 创新点与竞品对比（2026-10-11）

> 目的：回答「本项目比市面上的项目多做了什么」，并给出把优势继续扩大的路线。
> 对比对象：同花顺、东方财富（行情资讯终端）；聚宽、米筐、Backtrader（量化回测框架）；各类 AI 荐股应用。
> 诚实声明：下表所有能力均为本项目代码实测可复现项（附模块路径），不含规划中功能；负向结论（方向预测≈随机）如实保留。

---

## 一、一句话定位

市面产品要么**只展示不决策**（同花顺/东财给你看数据，决策靠你自己拍脑袋），要么**只回测不决策**（聚宽/米筐/Backtrader 给你框架，仓位与风控仍是黑盒），要么**荐股但不可解释不可复盘**（AI 荐股类，黑箱输出、无法对账）。

StockSignal 补的是**从数据到「可解释、可自纠偏、可验证」决策的最后一公里**：行情/事件/回测/持仓/决策整合成一条链路，每条建议带依据、每天留快照、每月能对账、错了能自纠。

## 二、八大创新点（vs 竞品均无或显著弱）

### 1. 决策闭环：四维→仓位，逐条可解释
`modules/decision.py::derive_position`：市场温度 + 情绪周期 + 梯队晋级率 + 事件因子四维推导仓位建议（clamp 5~95%），**每条调整都输出人类可读的 reasons**（如「市场温度 34 作为基准仓位 → 退潮减仓 10% → 梯队断档减仓 6%」）。
- 同花顺/东财：无仓位推导；聚宽/米筐：仓位在用户自己策略里，平台不管。
- 竞品差距：**没有任何竞品把「建议仓位 + 逐条理由 + 每日归档」做成一等公民。**

### 2. 刻度校准自纠偏：系统会自己认错
`calibration.py`：按历史回测反推各周期仓位刻度偏差，给出**有界**（±5pt 内）调参建议；样本不足时**拒绝表态**（accuracy=null 不是 bug 是设计）。
- 竞品：荐股错了不会告诉你它错了，更不会自动修正刻度。

### 3. 诚实数据语义（全站工程纪律）
数据不可得 → 返回 `unavailable` 并如实标注，**绝不编造、绝不默认 0**；预测对账 `prediction_log` 逐条留痕；小样本不显著性推断写进论文与产品。
- 这是与「AI 荐股」类产品最本质的价值观差异：它们卖确定性，我们卖可核验。

### 4. 事件因子「证伪护栏」
`modules/event_factor.py`：历史回测若证明某事件催化「开」的命中率不优于「关」，系统自动判定为噪声并停用——**让事件驱动成为可证伪主张而非装饰标签**。

### 5. 真实成本模型 + 可核算性验证
`modules/backtest.py`：买入 `price×(1+滑点)×(1+佣金)`、卖出扣佣金+印花税，乘性叠加防重复扣费；论文第 6.4 节用同区间双组回测证明成本拖累可逐笔核算（0.5%/往返）且不干扰时序。
- 聚宽/Backtrader 有成本模型但无「可核算性验证」叙事；同花顺模拟炒股成本近似拍脑袋。

### 6. 多算法融合荐股，逐算法归因（本期新增）
`modules/recommend_engine.py`：multi_factor V5（趋势 50+动量 30+波动 15+量能 15）、双趋势共振（GMMA+一目+ADX）、资金流、事件因子、动量广度五路算法独立打分 → 分位归一化加权融合，**每只推荐股附每路算法的得分与理由**，并给买入方案（入场/目标/止损/仓位）。
- 竞品荐股是黑箱评分；我们做到「为什么推荐它」可展开到每一路算法。

### 7. 万级虚拟用户蒙特卡洛验证（本期新增）
`scripts/simulate_virtual_users.py`：1 万虚拟用户 × 不同风险参数 × 随机入场时点，在真实历史行情上跑完整交易模拟（含成本），聚合回报分布（p5/中位/p95）、最大回撤、胜率、正收益占比——**方案的商业可行性用分布说话，不用单一样例讲故事**。

### 8. 数据资产：4798 交易日全市场广度情绪史
`data/shepherd_history.csv`（2007–2026，含 2009-11 起方向可评分口径 4092 日）：离线可复现、防覆盖双备份，支撑大规模回测（论文 6.6：诚实结论「方向预测≈随机」）——**用数据证伪自己，再用证伪结果指导产品设计**（预测不可靠 → 把可靠性预算花在仓位刻度与风控上）。

## 四、优势扩大路线（按投入产出排序）

1. **荐股闭环化（本轮已做）**：每日推荐 → 次日自动对账（推荐价 vs 实际走势）→ 命中率进消息中心 → 校准器消费。竞品荐股「发完即忘」，我们让每次推荐都可被审计。
2. **组合级方案**：从「5 只个股各给仓位」升级为「组合方案（相关性约束 + 行业分散 + 总仓位联动 derive_position）」——竞品没有组合级可解释方案。
3. **Regime 自适应策略**：把市场温度接到策略开仓闸门（冰点空仓），walk-forward 验证——把论文已证明的「方向不可测」转化为「 régime 可测」的仓位价值。
4. **模拟器常态化**：每周自动跑 1 万虚拟用户回归，方案漂移（胜率/回撤恶化）自动告警进消息中心。
5. **开放 API / MCP**：荐股与决策闭环输出为 MCP 工具（已有 mcp_server 底座），让第三方把我们的可解释决策嵌进他们的工作流——竞品的决策能力不可嵌入。
6. **社区策略市场**：策略注册表（STRATEGY_REGISTRY）已插件化，开放第三方策略接入 + 统一归因评估——聚宽有社区但无「逐算法归因 + 对账」。

## 五、边界与诚实声明

- 方向预测≈随机是**已用 4092 交易日证伪的结论**；本项目推荐的价值主张是「筛选漏斗 + 风控方案 + 成本感知 + 可对账」，**不承诺预测涨跌**。
- 虚拟用户模拟为蒙特卡洛回测模拟，非实盘；股票池基于现存上市代码，存在幸存者偏差，报告中已披露。
- 所有推荐均附「不构成投资建议」声明与数据时点标注。
