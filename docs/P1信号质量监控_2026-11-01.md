## 3. 体检维度与语义

### 3.1 结构体检（红灯 = 阻断）
- 文件存在 / JSON 可解析 / 顶层为对象
- 必备字段：`model / latest_date / horizon / top_long / top_short / daily`
- `latest_date` 合法 ISO 日期
- `top_long` / `top_short` 非空列表，每条含 `symbol/pred/rank`
- symbol 格式：`sh/sz/bj + 6 位数字`
- rank 排序：看多榜非增（1.0 最强在前）、看空榜非降（最小 = 最强看空）

### 3.2 新鲜度 SLA（红灯 = 阻断）
`age = max((today - latest_date).days, 0)`，按模型阈值（默认，可 `--max-age k=v` 覆盖）：

| 模型 | SLA（自然日） | 说明 |
|---|---|---|
| baseline / ev / gru / ens | 8 | 覆盖周末（周五生成 → 周一查仍绿） |
| fusion | 8 | 当前真实滞后 20 天 → 红灯，暴露数据源停更 |

### 3.3 ens↔baseline 对齐守望（黄灯 = 登记不阻断）
`Jaccard(ens.top_long[:20], baseline.top_long[:20])` ≥ 0.75 → 绿（降权语义成立）；
低于阈值 → 黄灯 + 提示「需 sj 侧核对 gru 权重是否回归 / z 序口径 / 数据版本错位」。
黄灯不改变退出码。

## 4. 使用方式

```bash
# 全量体检（Markdown 报告；红灯 → 退出码 1）
python scripts/p1_signal_quality_report.py

# 指定目录 / JSON 输出 / 覆盖阈值
python scripts/p1_signal_quality_report.py --dir data/p1_signals --json
python scripts/p1_signal_quality_report.py --max-age fusion=25 --max-age ens=3
```

建议接入：
- 定时任务（每日开盘前扫一次，红灯 → 企业微信/飞书告警）；
- 或并入现有推送链尾部环节（S13 之后追加体检步骤）。
