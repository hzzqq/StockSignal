## 一、结论先行 · 最优组合推荐

**推荐方案（🟢 低风险主线）：**
- **保留项目靛紫身份令牌** `--acc1:#4f46e5 / --acc2:#7c3aed`（老板已冻结，改动风险高，非必要不动）。
- **默认画布切「暗色终端」**：底色 `#0E0E0E` 系（吸收 QuantDinger），浅色作为可切换副主题，不再作为默认。
- **结构密度吸收 QUBE**（黑白极简的卡片间距与边线克制感）。
- **个股信息架构吸收 AI2Alpha**（左主图 + 右因子/舆情分栏的纵向密度）。
- **数字排版节奏吸收 QuantDinger**（等宽数字 + 大字号涨跌幅 + 弱网格）。
- **A股语义色保持不变**：涨 `#ff4d4f` / 跌 `#00d486`（红线硬约束）。

**为什么是它（3 条硬理由）：**
1. 令牌已冻结，本方案零触碰身份色 → 不触发全站回归，风险最低。
2. 24 张外部参考里 5/8 为暗色终端语系，最贴合量化交易场景，且与现有 `_KIT_CSS` 的 `.xc-*` Bento 体系天然同构。
3. 组件优化试点（`10_行情看板` 板块卡已收口 `xc_kpi_grid`）方向一致，可平滑铺开。

**风险分级：**
- 🟢 低：组件收口到 `xc_kpi_grid` / `chart_card` / `table_wrap`、间距 8px 栅格、暗色描边替代阴影。
- 🟡 中：默认主题切暗色需双主题回归（守卫 `test_ui_design_system.py` + 冒烟 `test_pages_smoke.py`）。
- 🔴 高：换身份色 / 推翻令牌 → **当前不动，需老板单独拍板**。

## 三、按功能页面拆解（5 维度）

### A. 行情看板 / 市场全景
- **对应文件**：`pages/10_行情看板.py`、`pages/57_市场全景.py`
- **参考**：DSA 首页工作台（现状）、行情中心+AI 抽屉（现状）、QuantDinger（暗终端布局）
- **① 布局**：左侧固定导航 + 顶部全局状态条（指数跑马 + 搜索） + 主区 Bento 网格（KPI 卡 → 板块涨跌榜 → 行情表 → 迷你图）；AI 问答做右侧滑出抽屉，不占主区。
- **② 配色**：画布 `#0E0E0E`；卡面 `#16161A`；强调靛紫；涨 `#ff4d4f` 跌 `#00d486`；网格线 `rgba(255,255,255,.06)`。
- **③ 组件**：KPI 卡走 `xc_kpi_grid`（已试点）；行情表走 `table_wrap`；搜索框统一 `ui_kit` 输入框；AI 抽屉用 `chart_card` 容器。
- **④ 排版**：数字等宽（ticker / 涨跌幅），标题 15px/600，标签 12px/400 灰 `#9ca3af`，涨跌幅 18–22px/700。
- **⑤ 间距阴影**：8px 栅格；卡圆角 12px；暗色用 1px 描边 `rgba(255,255,255,.06)` 替代投影（或 `0 1px 3px rgba(0,0,0,.4)`）。

### B. 今日决策面板

- **② 配色**：同 A 暗色体系；仓位建议用靛紫填充块；归因正负用涨/跌色。
- **③ 组件**：`page_hero` 承载仓位建议；`xc_section_header` 分节；归因条形用 `xc_kpi_grid` 变体或原生 `st.progress`。
- **④ 排版**：Hero 仓位 32px/800；分节标题 14px/600；因子名 13px/500。
- **⑤ 间距阴影**：节间距 24px；卡内 padding 16px；圆角 12px。
