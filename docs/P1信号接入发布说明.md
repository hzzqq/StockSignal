# P1 量化信号接入 StockSignal · 发布说明

> 面向团队的接入与发布纪要。代码层已完成，本文固化「交付内容 / 口径 / 验证状态 / 排错」。

## 一、背景与目标
把 **P1-QuantFactor**（1427 只 A 股训练的 GRU 神经网络，EV 模型并入「牧羊人市场广度情绪」9 维事件因子，共 47 维）产出的量化信号，接入 StockSignal 作为**事件驱动参考层**。
- 与 StockSignal 既有的 `modules/signal.py`（价格/事件/宏观/板块 0-100 评分引擎）**相互独立、互补**，不是同一套东西。
- 与「牧羊人情绪信号」互补：**情绪定仓位（该几成仓），P1 定个股（仓里买什么）**。

## 二、交付内容（文件清单）
| 文件 | 作用 |
|---|---|
| `modules/p1_signal.py` | `P1SignalLoader` 加载器：懒加载 + 缓存 + **mtime/ttl 实时刷新**（P1 重导出即重载，5min 内走缓存）+ `invalidate()` 手动清缓存 |
| `pages/55_P1量化信号.py` | 独立信号页：看多榜（红）/看空榜（绿）+ 三信号 A/B 重叠（Jaccard）+ 个股近 40 日得分线图；每 5 分钟自动刷新 + 手动刷新按钮 |
| `pages/54_今日决策面板.py` | 在「连板梯队」后新增 `fragment_p1_ev()`：EV 看多榜**多头侧灰度参考**（前 15，红涨色），明确「候选池 / 非买入指令」 |
| `data/p1_signals/README.md` | drop-in 部署说明 + 信号 JSON 结构 |
| `data/p1_signals/VERIFY.md` | 真机验证清单（逐项勾选 + 回归测试命令） |
| `data/p1_signals/signal_{baseline,ev,fusion,gru}_h10.json` | 4 个真实信号文件（已就位） |

## 三、如何使用
1. 信号文件就位：`data/p1_signals/` 下 4 件 `signal_*.json`（已复制），或设 `P1_SIGNAL_DIR` 指向信号目录。
2. `streamlit run app.py` → 侧边栏自动出现「55_P1量化信号」页；「54_今日决策面板」页内出现 P1 参考区块。
3. 默认模型 EV（全量 1427 严格 hold-out 口径最优）；可切 baseline/gru/fusion。
4. 刷新：页面内「🔄 刷新信号」/「🔄 刷新」按钮；或交易时段静置 5 分钟自动刷新。

## 四、口径铁律（务必在页面 / 文档 / 群内明示，不可省）
1. 这是**统计意义上的超额收益概率排序**，**不是**「明天必涨/必跌」的预测。
2. **2026 单年口径订正**：此前「仍为负」系 rf=15 错配桶（信号 10 日窗口在 15 日持有中衰减）所致；阶段 18/19 改用 rf=10（=horizon，非重叠桶）后 2026 已转正——GRU +8.67%、EV(fusion) +11.56%，多年度（2022–2026）复合正期望不变。
3. 信号为**市场中性多空**，A 股零售场景建议**仅取多头侧**。
4. EV 看多榜是「候选池 / 参考」，**不是买入指令**；与牧羊人情绪信号互补（情绪定仓位、P1 定个股）。

## 六、排错
- 页面报「未找到 P1 信号文件」→ 确认 `data/p1_signals/` 四文件在，或设 `P1_SIGNAL_DIR`。
- 信号不更新 → 点刷新按钮，或确认 P1 重导出文件 mtime 已变。
- 首屏慢 → gru/fusion 各 ~55MB，首次数秒，之后 5min ttl 走缓存。
- 真机不在本机 → 信号文件需随 StockSignal 部署；勿依赖 `E:/project/sj/data/P1/processed/signals` 这一沙箱硬编码回退路径。
