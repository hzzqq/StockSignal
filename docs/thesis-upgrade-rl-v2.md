# RL 仓位策略 v2：从「策略坍缩」到「上限诊断」——改进实验补充节

> 毕设素材 · 追加于《强化学习仓位策略对照实验》之后（T-265 A 路）。所有数字来自 P1 同口径 head-to-head 真实重跑（walk-forward 2022–2026，horizon=10，COST=0.001，组合构建与指标函数与 38_rl_position.py 逐字节复用，保证 head-to-head 公平）。原章节的负向结果（REINFORCE/Actor-Critic，总体 Sharpe -0.741）**保留不删**，作为演进叙事的第一阶段。

## 一、v2 的三点结构性修正（针对失效机制，非超参补丁）

原版诊断指出：自由动作策略在强信号上「动作自由度过大 + 无锚定」，坍缩到近恒定小仓位（换手 0.026），丢失满仓暴露。v2 据此做三处修正：

1. **乘性调制参数化（保底设计）**：`a = clip(b0·(1+κ·gθ(s)), -1, 1)`，其中 `b0 = tanh(2·pred_z)` 为原最优静态基线动作，`gθ∈[-1,1]` 由**零初始化末层**策略网络输出，κ=0.8。训练起点严格等于基线；策略只学「相对基线的增减仓调制」，满仓暴露永不丢失。
2. **基线锚定 advantage**：`adv = [r(a) − r(b0)] − V(s)`，其中 `r(b0)` 为基线动作在同 (symbol,date) shift 链下的奖励（预计算常数）。策略只有**跑赢基线**才获得正梯度，从机制上消除「偏离基线即白付换手费」的坍缩激励。
3. **状态扩展**：`state = [pred_z, mom_z, vol_z, pos_z, bias_z, |pred_z|]`——新增信号自身置信度（调制策略理应学「何时信任信号」）。训练轮数 15→40（cosine lr）。

## 二、可学上限诊断（oracle）：回答「RL 到底能不能赢」

在训练 RL 之前先回答一个更根本的问题：**允许「按波动状态直接选缩放系数」的可学上限在哪里？** 做法（严格无泄漏）：vol_20_z 按训练年分位分三桶；每桶的缩放系数 λ* 从网格 {0.5, 0.75, 1, 1.25, 1.5, 2.0} 中按训练年决策日平均奖励选出；测试年按同桶应用。若该 oracle 上限也无法超越静态基线，则任何 RL（上限 ≤ oracle）都不可能赢。

## 三、实验结果（真实重跑，39_rl_position_mod.py）

| 方法 | 总体 Sharpe | 总体总收益 | 胜率 | 最大回撤 | 平均换手 |
|---|---|---|---|---|---|
| v1 RL（原版 Actor-Critic，引用原章节） | -0.741 | -0.991 | 0.442 | 0.997 | 0.026 |
| **w_mod（v2 乘性调制 RL）** | **+0.549** | +11.8 | 0.571 | 0.865 | 0.082 |
| w_oracle（可学调制上限，严格无泄漏） | +1.163 | +876.7 | 0.602 | 0.881 | — |
| w_sign（满仓多空） | +1.150 | +337.5 | 0.599 | 0.807 | — |
| w_tanh（基线） | +1.137 | +271.1 | 0.612 | 0.749 | — |

分年（Sharpe）：2023 mod -0.101 / oracle 0.335 / tanh 0.682；2024 mod +1.198 / oracle 1.885 / tanh 2.418；2025 mod +0.631 / oracle 2.169 / tanh 0.877；2026 mod +0.796 / oracle 1.100 / tanh 1.234。v2 策略平均 |g|=0.96（调制幅度充分激活，非 v1 的 0.026 塌缩）。

## 四、结果分析（如实表述，不夸大）

1. **结构修正确实有效**：同样的信号、同样的 RL 框架族，仅将「自由动作」改为「基线乘性调制 + 基线锚定 advantage」，总体 Sharpe 由 **-0.741 修复至 +0.549**（由深负转正，换手 0.026→0.082，调制幅度充分激活）。这验证了失效机制诊断的正确性，本身构成方法学贡献：**在强信号上做 RL 后处理，参数化方式（锚定与否）比训练算法（REINFORCE vs Actor-Critic）重要得多**。
2. **但 v2 仍未超越静态基线（+0.549 vs +1.137）**，且**决定性证据来自 oracle 上限**：可学上限（+1.163）与两条静态基线（+1.150 / +1.137）统计上持平，分年互有胜负（2023/2024 上限甚至低于基线）。**结论升级：不是 RL 训练不行，而是「状态调制」在这条强方向性信号上根本不存在可榨取的超额信息**——oracle 拿着「上帝视角选参」也只能打平。原章节的推断（「调制无正收益空间」）由此从假设变为实证。
3. **对本毕设的叙事价值**：本章由此形成完整的三段式方法论闭环——①自由动作 RL 失效（v1，Sharpe -0.741）；②针对失效机制的保底重设计使 RL 回到正收益（v2，+0.549）；③可学上限诊断证明该信号上调制空间不存在（oracle ≈ tanh）→ **「何时该用 RL 做仓位调制」的判据**：当且仅当 oracle 上限显著高于静态映射时，RL 才值得投入。这一判据可迁移至任何「信号→仓位」场景。
4. 边界如实说明：oracle 在 2025 年分桶 Sharpe 2.169 显著高于基线 0.877，说明波动状态在个别年份确有信息，但跨年不稳定（2023/2024 为负增量），不足以支撑通用调制策略。
