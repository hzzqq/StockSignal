[开源] 我做的 A 股事件驱动分析平台：4 数据源自动降级 + 38 页面 + 1767 测试

## 正文（从下一行开始复制）

做了个 A 股事件驱动投资分析平台，开源免费，分享给感兴趣的 V 友：

**特点**
- 4 大免费数据源自动降级（AKShare / BaoStock / 新浪 / 东方财富），本地 SQLite 缓存，断网也能看历史
- 38 个功能页面：行情看板 / 事件追踪 / 策略回测 / 资金流向 / 市场情绪 / 模拟交易 / 智能条件单 / AI 投研
- 1767 个自动化测试兜底（含数据正确性断言）
- Windows 双击 bat 一键启动，Docker 也行

**快速开始**

```bash
git clone https://github.com/hzzqq/StockSignal.git
cd StockSignal
pip install -r requirements.txt -r backend/requirements.txt
python -m backend.scripts.init_db
python -m flask --app backend.app:app run --port 5050 &
streamlit run app.py
```
