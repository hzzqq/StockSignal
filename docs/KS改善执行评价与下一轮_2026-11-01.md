### 1.2 ⚠️ P0 阻断事故：R-14（6b25160）破坏 modules 导入链（HEAD 上仍存在）

**现象**：全量 pytest 首跑 **22 个测试文件收集 ERROR**——`NameError: name 'TTL_TIERS' is not defined`；守卫三件套大面 FAIL；`import modules.linear_trends` 直接崩溃。

**根因**（已精确定位）：R-14 在 3 个文件把 `from modules.cache_utils import TTL_TIERS` **误写进模块 docstring 三引号内**（非导入语句，纯文本）：

| 文件 | 事故位置 | 引用点（因未导入而崩溃） |
|---|---|---|
| modules/fundflow.py | docstring L2 | L153 `def _cache(ttl=TTL_TIERS["sentiment"])`（默认参数求值即崩） |
| modules/spot_rank.py | docstring L2 | L211 `@st.cache_data(ttl=TTL_TIERS["quote"])` |
| modules/widgets.py | docstring L2 | L1035 `@st.cache_data(ttl=TTL_TIERS["quote"])` |

**影响链**：modules 导入链断裂 → app.py 导入即死 → 22 个测试文件收集失败 → 全量测试无法运行（skip 率无法测量）→ 任何依赖 modules 的页面启动即崩。**该事故随 6b25160 进入 HEAD，df9f209 未修复**。

**当前状态**：主工作区已有等价修复（3 文件 import 归位，注释「修复：此前误写进模块 docstring 内未执行」）但**未提交**（git status M）；本空间已在隔离 worktree 复现并验证修复（143 模块导入 bad=0），因主工作区已有等价修复，未重复提交。
