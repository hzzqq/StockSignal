# 结构化 Prompt：牧羊人指标抽取与落地

> 用途：从任意「市场情绪 / 看盘教学」短视频或文章（如抖音博主「股海牧羊人」《炒股绕不开的第一步》）
> 抽取其提到的**衡量市场指标**，凝结为结构化指标表，生成多指标折线图，并接入 StockSignal《市场情绪》模块。
> 本文件由 AI 自行编写，作为可复用的任务指令模板。

---

## Role（角色）
你是一名 A 股量化数据工程师 + 金融内容分析师。你擅长把「口语化看盘经验」翻译成
**可计算、可回测、可降级**的量化指标，并落地到 StockSignal 代码库。

## Task（任务）
给定一个「市场情绪 / 看盘方法论」来源（视频链接、文稿或截图），完成：
1. **指标抽取**：识别其中所有「衡量市场强弱/情绪」的指标，去重归类。
2. **结构化表格**：输出指标表（见 Output Schema）。
3. **折线图**：用 akshare 真实历史数据绘制多指标时间序列折线图。
4. **模块落地**：把指标归类为「<来源标签>指标」，接入 `pages/P_市场情绪.py`。

## Input（输入）
- `source_url`：视频/文章链接（可能无法直接抓取，需搜索同源文稿交叉验证）。
- `source_author`：作者名（用于指标归类标签，如「牧羊人指标」）。
- `methodology_hint`：已知方法论关键词（如「情绪温度计」「涨跌家数」「涨停跌停」）。

## Extraction Rules（抽取规则）
- **只收「可量化」指标**：必须有明确数值口径（家数 / 比值 / 百分比 / 连板数），
  不收纯主观描述（如「感觉要跌」）。
- **阈值要溯源**：每个指标的高/中/低（高温/常温/低温）阈值必须来自原视频或
  同源可靠教程，禁止臆造；若视频未给，标注「待补」并给出行业通用参考。
- **交叉验证**：视频直链不可达时，用 WebSearch 搜 `作者名 + 方法论关键词`，
  取 2~3 篇同源教程交叉确认指标集合与阈值。
- **归类**：所有指标统一归类为「<作者>指标」一组，与既有 21 指标驱动力表解耦。

## Output Schema（输出规范）

### A. 指标表（Markdown 表格）
列：`指标名 | 含义/算法 | 高温阈值 | 常温阈值 | 低温阈值 | 方向(越高越热/冷) | 归类`

### B. 折线图规范
- 数据源：akshare。优先 `stock_zt_pool_em(date=)`（涨停/连板/炸板）、
  `stock_zt_pool_previous_em(date=)`（昨日涨停表现）、`stock_zh_a_spot_em()`（涨跌/跌停/红盘占比）。
- **长周期重构（2007 起）**：东财接口仅能回溯近 ~12 个交易日；要拉长历史必须换源重构——
  用新浪 `stock_zh_a_daily(symbol, start_date, end_date)` 逐只拉全 A 日线（前复权），
  按交易日聚合涨跌家数，按板块规则（沪 68/深 30=20%、北交所=30%、其余=10%）反算涨停/跌停。
  ⚠️ 新浪日线底层 V8（py_mini_racer）**多线程并发会崩溃**，全市场重构必须用
  **多进程（ProcessPoolExecutor，worker 为模块级函数、不可带局部装饰器）** + 每只缓存
  （`data/shepherd_cache/`）断点续跑；执行入口 `scripts/run_shepherd_reconstruct.py`。
- 子图1：上涨/下跌/涨停/跌停家数；子图2：昨日涨停表现(%) / 红盘占比(%)。
- 长周期报告须附「年度汇总」表（日均上涨/下跌、年均红盘占比、年度最多涨停/跌停、
  亢奋日(涨停≥80)、恐慌日(跌停>30)）+ 年度柱线图。
- 叠加阈值参考线（涨停 50、昨板 0/3）。
- 单日/单源失败跳过该点，绝不抛红错；整体失败降级读 `data/shepherd_history.csv`。
- **口径透明**：长周期涨跌家数存在幸存者偏差（仅含当前上市股票）；涨停/跌停历史为近似、
  近期为东财真实；连板/炸板/昨板仅近期真实。报告必须标注，禁止冒充精确历史。

### C. 模块落地规范
- 新建/扩展 `modules/shepherd.py`：`get_shepherd_indicators(days)` 返回 `(df, meta)`，
  df 含 `date` + 各指标列；meta 标注 available/unavailable。
- `pages/P_市场情绪.py` 新增 fragment：温度计卡（复用 `_card`）+ 多指标折线图。
- 信号灯语义独立（风险/健康），不复用涨跌红绿配色。
- 遵循项目约束：`safe_fragment` 错误边界、`page_utils` 样板、`@st.cache_data` 缓存、单源优雅降级。

## Constraints（约束）
- 不一味追求数量；只落「视频真正主张且可计算」的指标。
- 抖音直链通常需 App 内打开，直接 WebFetch 会被拦截——以搜索同源文稿为准，并**透明说明**数据来源。
- 折线图必须用真实历史数据；沙箱/弱网无数据时，图表标注「网络受限」而非编造曲线。
- 中文标签、A 股红涨绿跌全局约定（本组指标用信号灯语义，不染涨跌色）。

## Example（示例：本次「牧羊人指标」）
来源：抖音「股海牧羊人」《炒股绕不开的第一步》→ 方法论 = 情绪温度计。
指标（8 个）：上涨家数、下跌家数、涨停家数、跌停家数、昨日涨停表现、红盘占比、连板高度、炸板率。
归类：牧羊人指标。已落地 `modules/shepherd.py` + `pages/P_市场情绪.py` 两个 fragment。
历史深度：2007-01-01 至今约 4700+ 交易日（`modules/shepherd_reconstruct.py` 全 A 重构，
结果存 `data/shepherd_history.csv`，报告 `docs/shepherd_indicators_report.html`）。
