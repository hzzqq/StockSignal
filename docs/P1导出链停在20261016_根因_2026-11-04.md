# P1 导出链停在 `latest_date=2026-10-16` 的根因（2026-11-04 核查）

## 一句话结论

**不是导出链、也不是 StockSignal 侧同步的问题，是 P1 日链的入口闸门一直判 `SKIP`。**
`p1_daily_scheduler` 要求当日 `bridge_run_*.log` 里出现 K 线桥接完成标志
（`KLINE DONE` / `BRIDGE ALL DONE` / `ALL KLINE DONE` / `BRIDGE_DONE`，
见 `P1-QuantFactor/scripts/p1_daily_scheduler.py:22`）；桥接侧 baostock 连续失败、从未打出完成标志，
于是每天决策 `SKIP reason=BRIDGE_INCOMPLETE` → 重训/预测/导出全链没跑 → `pred_*.parquet` 停在 10-16，
`06_export_signal.py` 如实把 10-16 写成 signal json。

**推论**：桥接不恢复，任何 StockSignal 侧同步都不可能让副本变新；同步只能如实报 stale。
