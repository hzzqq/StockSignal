# 我做了一个开源的 A 股分析平台：38 个页面、不依赖任何券商接口、1767 个测试兜底

> 这是我在软件工程实训期间独立开发并开源的项目 **StockSignal**。把它写出来，既是对自己这段时间的总结，也想让更多对 A 股量化 / 数据分析感兴趣的朋友能直接拿来用、拿来改。

---

## 一、为什么又造了一个轮子？

市面上的行情软件要么收费、要么只给看不给出、要么接口要各种 token 才能跑通。我想做一个**纯免费、能本地跑、断网也能看历史**的 A 股工作台：把「事件 → 主线 → 回测 → 交易」串成一条链路，而不是一堆零散的脚本。

核心诉求就三个：

1. **数据源不能挂**——所以做了 4 级自动降级；
2. **功能要全**——所以堆到了 38 个页面；
3. **代码要靠谱**——所以写了 1767 个测试兜底。

---

## 二、它到底能干什么？

### 📊 行情与分析
- **行情看板**：K 线支持日 / 周 / 月切换、十字光标、双击弹分时、区域缩放；技术面四大维度（趋势 / 动量 / 量能 / 形态）一键拆解；板块涨跌榜实时热力。
- **个股分析**：单只股票的全维度拆解——K 线、技术面、财务、资金、新闻情绪。
- **多股对比**：一次对比 ≥5 只标的的走势 / 收益 / 相关性。
- **智能选股 / 形态选股**：多策略筛选 + K 线形态扫描。

### 📰 事件驱动（这个项目的主线）
- **事件追踪**：政策 / 并购 / 涨价 / 公告等催化事件聚合，利好利空标注（利空标在 K 线下方）。
- **每日晨报**：一键生成当日市场简报。
- **市场驱动力 / 板块轮动**：帮你找主线、看轮动节奏。
- **股吧热帖**：舆情与情绪面监控。

### 💰 资金与情绪
- **资金流向**：主力 / 北向 / 板块资金。
- **市场情绪 / 市场强弱**：情绪指标（ADL / ADR / PE / 股息率 / 涨停数）+ 市场温度。
- **财报日历 / 基本面分析**：业绩披露日历 + 财务三表。

### 🧪 策略与交易
- **策略回测**：Backtrader 引擎，含佣金万三 / 印花税千一 / 滑点成本。
- **模拟交易 / 实盘交易 / 智能条件单 / 价格预警 / 智能盯盘**。

### 🤖 AI 与辅助
- **星辰 AI · 多市场智能股票分析师**：全局侧边栏 AI 咨询，持续对话。
- **QuantAgent 投研**：量化研究助手。
- 新手教程 / 数据导出 / 用户管理 / 系统配置。

## 三、最让我得意的一个设计：4 级数据源降级

```
AKShare → BaoStock → 新浪财经 → 东方财富 → 本地 SQLite 缓存
```

任何一个数据源挂了，自动切下一个；都挂了还有本地缓存兜底。**任何单一数据源不可用都不会让页面崩**，断网也能看历史数据。这对一个学生项目来说，是能不能"体面地演示"的命门。

## 四、工程质量（认真写的代码）

- **1767 个测试全过**：数据正确性断言（OHLC 自洽 / 日期单调 / 股息率反推区间）、38 页离线冒烟（整批不卡死）、后端安全回归 12/12。
- 统一 JSON 响应 + 全局 errorhandler，**绝不泄露 HTML / traceback**。
- 安全基线：JWT + 限流 + 默认 TLS 校验 + 登录持久化。
- God Module 持续拆分、共享有界线程池、超时分层。
- CI：`.github/workflows/ci.yml` 自动跑测试。

## 五、怎么跑起来？（复制即跑）

```bash
git clone https://github.com/hzzqq/StockSignal.git
cd StockSignal
pip install -r requirements.txt -r backend/requirements.txt
python -m backend.scripts.init_db
python -m flask --app backend.app:app run --port 5050   # 终端1
streamlit run app.py                                     # 终端2
```

Windows 用户直接双击 `启动StockSignal.bat` 一键启动；也支持 Docker Compose 一条命令起。

默认账号：`demo / Demo@123`（体验全部功能）、`admin / Admin@123`（管理后台）。

界面截图都在 GitHub README 里（6 张真实数据渲染图，非占位图）。
