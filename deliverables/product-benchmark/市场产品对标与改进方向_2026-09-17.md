## 二、我们有什么 / 缺什么（代码实证）

### 护城河（别人弱或没有，且已在代码里）
- **事件驱动全链路**：`pages/23_事件追踪` / `60_事件对比分析` / `51_每日晨报` / `54_今日决策面板` + `modules/event_factor.py` + P1 量化信号（`55_P1量化信号`）。
- **情绪·温度体系**：`50/59/63/65/68/69` 六页 + `modules/shepherd*.py`（牧羊人 8 项指标）+ `temperature_backtest.py`（冰点→次日红盘 89.7%）——**商业产品没有等价的"可回测情绪体系"**。
- **市场结构**：`56_市场状态机` / `57_市场全景` / `58_连板龙头共振` / `70_涨停复盘`。
- **因子研究**：`modules/factor_analysis.py` 已有 rank IC / IC 时序汇总(IR/t 值/胜率) / 分层收益 / 多空组合（G3）。
- **诚实数据治理（独有）**：`82_数据时效性看板` + 决策闭环主动报警 + HTTP 快照回退（`request_utils.fetch_with_snapshot`，"绝不合成数据"）+ 数据源熔断 + 新增免费代理池。**商业产品几乎不披露"这个数是什么时候的、会不会停更"**。
- **决策闭环 + 命中率累积**：`modules/decision_track.py` + `daily_snapshot.json` + 校准（`calibration.py` 论文 49.1% 方向命中）。
- 本地优先、68 页、3197 测试、MCP 16 工具。

### 短板（市面产品吊打我们的地方）
- **AI 是"单轮问答"，不是"多步智能体"**：`modules/ai_engine.py::ai_answer` 是"取数 → 拼 prompt → 出答案"的一次性流程，无多步工具调用、无任务拆解过程可视化、**结论不带数据出处/时间戳**。对照：财搭子多智能体拆解、同花顺问财、东财妙想、米筐 AI Agents。
- **个股估值深钻不足**：只有"市场级 PE 历史百分位"（`market_drivers`）与"个股 5 年价格分位"（`fundamental_helpers`），**缺个股 PE/PB band、行业相对分位、杜邦 ROE 拆解、EV/EBITDA**。对照：理杏仁/萝卜。
- **无产业链图谱 / 事件传导**：有 `75_题材热点`，但**没有上下游图谱，也没有"事件→受益股"穿透**。对照：财联社题材雷达、芝麻 AI 受益股、萝卜产业链。
- **组合风险透视薄**：`portfolio.py::pnl_attribution` 只做盈亏归因，**缺行业/风格/因子暴露、相关性矩阵、集中度、压力测试/情景推演、再平衡建议**。对照：米筐 RQBeta/RQAMS、雪球组合。
- **回测稳健性缺口**：有 `param_grid`，**缺 walk-forward/样本外、参数敏感性热图、过拟合提示、因子衰减/正交**。对照：米筐/BigQuant。
- **无个股风险扫描**：`商誉` 只作筛选标签（`stock_screener`）、`解禁/减持` 只在新闻关键词（`_news_io`），**无商誉/质押/解禁/减持/诉讼/ST 风险仪表盘**。
- **主动推送没闭环**：有 `74_告警引擎` + `94_消息中心`，但缺"触发即推到微信/桌面"的默认通道（已有 `wechat-bridge` skill 可复用）。
- **无分享/传播**：单机工具，策略与看板无法沉淀传播（雪球/聚宽的核心）。

|---|---|---|---|:-:|:-:|

## 四、路线图（三波）

- **第一波 · 快赢（低成本高确定性）**：H6 风险扫描 → H7 推送闭环 → H5 回测稳健性 → H8 一键研报。都是"补最后一段"，复用已有模块与 skill。
- **第二波 · 加深护城河**：H2 估值深钻 → H4 组合 X-ray → H3 事件传导图谱。让"事件驱动 + 基本面 + 组合"真正咬合。
- **第三波 · 拉开代差**：H1 AI 研究智能体。把 MCP 16 工具 + 全部页面能力做成 Agent 的"手"，配合**引用溯源**，形成商业产品也难复制的"**可复现的本地研究台**"。

---

## 五、加倍下注：把"诚实数据治理"做成产品级卖点

市面产品几乎都在拼"更快更全"，**没人拼"更可信"**。而我们有现成的、别人没有的东西：
- 数据时效看板（每个源的 as_of / 滞后天数 / 停更检测）
- HTTP 快照回退（失败回退**上次真实快照**并如实标注，绝不合成）
- 数据源熔断 + 免费代理池（抗封禁）
- 决策闭环主动报警 + 每日快照 + 命中率累积

建议把这条线**产品化**为"H1 的引用溯源底座"：任何 AI 结论、任何指标卡，都能点开看到 **数据源 / 数据日 / 抓取时间 / 是否回退**。一句话定位：**"别的工具告诉你结论，我们还能告诉你结论是怎么来的、可不可信。"**

---

## 六、一句话结论

功能广度我们已经不虚（68 页覆盖了市面产品 80% 的能力），**真正的差距在三点：AI 是不是智能体、事件有没有传导到标的、组合有没有风险透视**。按 H1–H8 推进，先补快赢、再加深护城河、最后用"AI 智能体 + 引用溯源"拉开代差。
