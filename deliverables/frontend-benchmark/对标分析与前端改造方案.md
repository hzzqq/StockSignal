## 四、设计风格总结（他们怎么设计的）

### TSP（工程化最完整）
- **密度高、卡片化**：一页一主题，信息密度大但不乱，靠分区+留白切分。
- **SSE 流式进度**：长任务（回测）不只等结果，实时推进度与中间态。
- **动态菜单**：把任意第三方/扩展数据字段配成一级菜单——**数据即页面**。
- **分层缓存**：只存 15 列基础数据，读取时现算 68 列指标与信号（存算分离）。
- 可借鉴：**长任务流式反馈** + **存算分离**（我们已有 chart_cache/cache_utils，方向一致）。

### 钱来终端（视觉冲击最强）
- **TradingView 暗色**：深底 + 高饱和涨跌色，K 线为主角。
- **仪表盘化**：六维情绪指数用**仪表盘**（冰点→沸点）而非数字。
- **热力图**：成分股用 **Squarified treemap**（方块面积=权重，颜色=涨跌）。
- **实时榜**：Top50 自动刷新 + 奖牌图标 + 评分进度条（视觉化排序）。
- 可借鉴：**仪表盘化情绪** + **treemap 热力图** + **评分条**（比纯数字表更有冲击力）。

### 悟空量化（信息架构最全）
- Vuetify3（Material 3）：规整、企业感，**六维雷达**呈现评分。
- 模块切得细（连板天梯/市场全景/全球市场/宏观/财报猎手…），每模块一页。
- 可借鉴：**雷达图做多维评分** + 模块边界清晰。

### FactorHub（功能最硬、设计最弱）
- Ant Design 6 标准件拼装，评测原话："**前端 UI 基本就是 AI 生成的风格，没什么设计感**"——**反面教材**：功能强不等于体验好。
- 但**流程串联**值得学：写公式→看指标→跑回测→解结果，四步在同一页面内闭环。
- 可借鉴：**工作流闭环** + **公式实时校验**（即时反馈）。

### Ghostfolio（留白与层级最好）
- Material 3 + **持续做「减法」**：降低按钮水平 padding、减小对话框圆角、清理废弃仪表板——**精致化靠抠细节，不靠堆元素**。
- **Zen Mode**：一键进入低干扰专注态。
- PWA + mobile-first。
- 可借鉴：**层级靠留白不靠卡片** + **主动做减法** + **专注模式**。

### OpenBB（架构最正）
- **Workspace / Dashboards / Folders / Grouping**：用户自建工作区，层级化组织。
- **命令面板 + Routines**：键盘高效操作 + 命令流水线。
- **术语标准化**（Stocks→Equity）：统一语言降低认知负荷。
- 可借鉴：**自定义工作区** + **术语统一** + **可组合（widget 拼装）**。

## 五、架构判断（诚实结论）

**结论：不换架构。** 理由：

1. **工具匹配度**：Streamlit 面向"数据分析/仪表盘"是合适选型；41 页 + 2500+ 测试 + 前后端分离已成型，换 React 是数月重写且会丢掉全部守卫测试。
2. **瓶颈不在架构**：我们的真实瓶颈是 **IA 分层（已改首页）+ 缺失模块 + 设计精致度**，不是框架能力。把 React 换进来，这些问题一个都不会自动消失。
3. **反模式警戒**：把"换成更时髦的栈"当优化目标，本身就是自欺（等价于"为漂亮改样式"）。

**但要承认 Streamlit 的能力边界**（做不到就明说，不硬凑）：
- 无法做真正的 SSE/WebSocket 服务端推送 → 用 `st_autorefresh` 轮询近似；
- 无法做拖拽布局（dnd-kit）→ 用配置化布局（下拉/多选）近似；
- 无法做 PWA/离线 → 明确不做。

**真正该改的三件事**：① 补 P0/P1 缺失模块（G1/G2/G3/G5）；② 设计系统继续统一（改 primitive 不迁调用点）；③ IA 继续收敛（首页已重排）。

## 六、改造路线（分批，P0 先行）

- **第 1 批（P0，本轮）**：涨停复盘 + 龙头识别 → 新页 `70_涨停复盘.py`，融合我们的连板梯队/炸板率/情绪周期，做**比钱来更系统**的版本（他们只有打板视角，我们有情绪周期 + 晋级率 + 温度交叉验证）。
- **第 2 批（P1）**：因子分析页（IC/IR + 分层收益 + 多空组合）；六维评分（并入个股研究）；自定义看板。
- **第 3 批（P2）**：告警规则引擎；treemap 热力图；命令面板；实时强势榜。
- **第 4 批（P3）**：财报猎手；Zen 模式；回测任务持久化。

每批都遵循：**改 primitive 不迁调用点** + **加 AST 守卫防回退** + **增量提交推送**。
